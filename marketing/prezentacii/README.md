# Презентации LOVII — индекс

Комплект из 5 презентаций (контент — 2 сентября 2026). Каждая дека — 21 слайд,
в двух форматах: **PDF** — для показа и рассылки, **PPTX** — исходник для правок.

| Файл | Аудитория / назначение |
|:---|:---|
| `LOVII_1_promty_guide` | Внутренний гайд по промтам для image-генерации: контекст бренда LOVII и сценарии промтов для нейросетевой генерации визуалов |
| `LOVII_2_partnery_predstaviteli` | Партнёрская программа — представителям: «представитель — человек, который знает свой район», зарабатывай на своём районе |
| `LOVII_3_ambassadoram` | Амбассадорская программа: «зарабатывайте на районе, который любите» |
| `LOVII_4_investoram` | Инвестиционная презентация: «инфраструктура локальной экономики» |
| `LOVII_5_klientam` | Для жителей района: программа лояльности района («1 балл = 1 ₽») |

Связанные материалы: инфопакеты амбассадора и представителя — `marketing/LOVII_инфопакет_*.pdf`.

> ⚠️ Числа внутри презентаций — не канон. При любом конфликте побеждает
> [`canon/PARAMS.md`](../../canon/PARAMS.md); перед показом инвесторам/партнёрам
> сверяйте цифры дек с каноном.
