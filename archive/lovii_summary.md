## 2. Концепция и стратегия

### Что такое LOVII

LOVII — это два в одном:
1. **Программа лояльности** для микробизнеса (баллы, кэшбэк, кросс-обмен)
2. **Цифровая витрина** — локальный каталог товаров и услуг (доставка, домашняя кухня, продукты, бьюти, рынки, курьерские услуги)

Каждая локация — отдельный экземпляр экосистемы: свой каталог, аудитория, логистика, команда (white-label, гео-изоляция).

### Стратегическая цель

Построить КИП (комплексную информационную платформу), КАРТУ, АР (агентство развития) — которая:
- Агрегирует локальные сервисы вместо конкуренции с федеральными (Яндекс, Ozon)
- Создаёт саморастущую экономику через реферальную модель
- Масштабируется через франшизу City Franchise

### Простая формулировка проекта

> «Лови — это приложение, где собраны все местные кафе, пекарни, магазины и сервисы твоего района»
>
> «Это как единая карта лояльности на весь район»
>
> «Как Яндекс.Еда, только вместо крупных ресторанов — маленькие местные кафе, пекарни, кондитерские. И одна программа лояльности на всё»

### Целевые партнёры в регионах

1. Локальные предприниматели с опытом в логистике/ритейле
2. Бывшие франчайзи других сетей
3. Операторы рынков/ТЦ
4. HR-директора крупных компаний (500+ сотрудников)

### Красные линии проекта

- Никакой перепродажи товаров
- Никакого % с выручки точек или брендов (доход — только роялти и ИТ-услуги)
- Сохранение ИТ-аккредитации
- Прозрачность всех комиссий и тарифов
- Агентская модель — все расчёты через БПА

### Актуальная модель (агентская, с июля 2026)

```
ООО «Аксиома» (Правообладатель, Платформа)
    │
    ├── Агентская модель (глава 52 ГК РФ)
    │   └── Номинальный счёт (ст. 860.1 ГК РФ) в Т-Банке
    │
    └── Лицензионное вознаграждение: 10% с чека
```

### Роли участников

| Сторона | Роль | Обязанности |
|---------|------|-------------|
| **ООО «Аксиома»** | **Агент** (коммерческий посредник) | ИТ-инфраструктура, фискализация (54-ФЗ), приём платежей |
| **Торговая точка (МСП)** | **Принципал** (владелец товара) | Товар/услуги, налоги с продаж (ИНН в чеке) |
| **Покупатель** | **Потребитель** | Оплата, получение чека |
| **АО «Т-Банк»** | **Технический исполнитель** | Номинальный счёт, мультисплит, выплаты |

### Документы

| Документ | Статус |
|----------|--------|
| Публичная оферта (для покупателей) | ✅ Активна |
| Оферта присоединения (для МСП) | ✅ Активна |
| Договор Т-Банк (Мультирасчёты) | ✅ Заключён |

### Финансовый контур

- Все деньги проходят через **номинальный счёт** Т-Банка (161-ФЗ)
- Платформа **не хранит деньги клиентов**
- Агентская модель **без перепродажи товаров**
- Фискализация силами Агента (облачная ККТ, 54-ФЗ)

## 5. Продукт и архитектура

### Архитектура (12 доменов)

1. **Общая архитектура** — ролевая модель, безопасность, темизация
2. **Клиентская часть** — витрина, заказ, лояльность, баллы, вывод, чаевые
3. **Бизнес-часть / ТСП** — каталог, заказы, касса, персонал, доставка
4. **Франчайзи** — управление точками, ПВЗ, рекламный доход
5. **Оператор** — тарифы, роялти, мониторинг, интеграции
6. **Логистика** — Igoods, Яндекс.Go, Чибис, Атмосфера
7. **Реклама** — Мобиап, баннеры, таргетинг, распределение дохода
8. **Кросс-лояльность** — конвертер валют, FMCG, офлайн-оплата через QR
9. **Финансы и юр. инфраструктура** — консолидатор, НПД, банковский партнёр (Т-Банк)
10. **HR и обучение** — портал, обучение, бонусы, рейтинги
11. **API** — REST/GraphQL, вебхуки, white-label виджет
12. **Дополнительно** — локализация, поддержка, модерация, AI-рекомендации

### Технические решения

- **Frontend:** React + Vite + Tailwind CSS (веб), React Native + Expo (мобильное)
- **Архитектура:** Микросервисы + event-driven (Kafka, CQRS, Saga Pattern)
- **БД:** PostgreSQL (кластер 2N+1), Redis, ClickHouse
- **Core-сервисы:** Go
- **PWA** для MVP (не нативные приложения на старте)

### Безопасность и compliance

- ФЗ-152 (персональные данные), ФЗ-161 (платёжные системы)
- ФЗ-54 (кассы), ФЗ-115 (антиотмывочный)
- PCI DSS для работы с банковским партнёром
- KYC/AML для вывода средств
- Хранение данных в РФ

### Реферальная программа (кэшбэк)

- Клиент получает 5% кэшбэка баллами
- Столько же (5%) отчисляется в фонд Лови
- Распределение фонда зависит от цепочки приглашений (3 сценария: А, Б, В)
- Клиент закрепляется за точкой, которая его пригласила

### Промокоды

- Формат: `PPXXXX` (6 символов: 2 символа префикс + 4 символа суффикс)
- Алфавит: 33 символа `23456789ABCDEFGHJKLMNPQRSTUVWXYZ` (без 0, 1, I, O)
- Ёмкость на один префикс: 33⁴ = **1 185 921** вариантов
- Всего префиксов: 33² = **1 089** (включая `AA` Основателя)
- Общий потенциал: **~1,29 млрд** промокодов
