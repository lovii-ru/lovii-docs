## Проблема (что видит владелец)

Экран `src/modules/auth-module/components/AuthCode.vue` (ввод 4-значного кода
после выбора канала MAX/Telegram/VK):

1. **Тексты наезжают друг на друга.** Условные блоки — «Проверяем код…»
   (`confirming`), таймер «Новый код можно получить через N сек.», кнопка
   «Отправить код повторно», ошибка повторной отправки — каждый со своим
   фиксированным `margin` (32px/40px) и появляются/исчезают независимо;
   длинные серверные тексты (блокировка с причиной, 429) ломают вертикальный
   ритм, на узких экранах строки наезжают, экран «прыгает».
2. **Поле ввода кода** — одно узкое подчёркнутое поле `max-width: 148px`
   с крупным шрифтом `h1-bold`: выглядит незавершённо, ошибка под полем
   добавляет ещё один наезжающий слой.
3. **Логотипа на auth-экранах нет вообще** (`AuthPhone.vue` / `AuthCode.vue` —
   ни одного `<img>`): экран входа без идентичности продукта.

## Референс — «как на пинкод-экране» (`src/modules/profile-security/components/AppLock.vue`)

Готовый, уже принятый в продукте паттерн (SZ-025) — повторяем его приёмы:

- **Логотип**: `@/assets/images/lovii-logo-dark.svg` (класс `app-lock__logo`)
  сверху карточки — тот же ассет и пропорции на OTP-экране;
- **Индикатор ввода**: точки/dots (`app-lock__dots`, состояние ошибки —
  `app-lock__dots_error`) — визуальный аналог для 4 ячеек кода;
- **Единая строка-подсказка** `aria-live="polite"`: состояние меняет **текст**
  («Введите код быстрого входа» ↔ «Неверный код — попробуйте ещё»), а не
  добавляет новый блок — именно это убирает наезды;
- **Карточка** `app-lock__card` + спокойный вертикальный ритм на токенах ДС.

## Требования

### Дизайн-часть (референс + ассеты)

1. Логотип — существующий канонический ассет `lovii-logo-dark.svg` (как в
   AppLock): размер/отступ сверху по ДС; второй логотип-вариант не создавать.
2. Поля OTP — **4 отдельные ячейки** (по одной цифре), интервал/радиус/фон —
   токенами ДС (`--lv-r-md` и шкала отступов); состояние ошибки — контур
   `--feedback-negative-solid`, как текущий `.error`.
3. Статусная зона — одна строка под полями (аналог `app-lock__hint`):
   «Проверяем код…» / «Новый код через N сек.» / «Отправить код повторно» /
   текст ошибки. Мин-высота зарезервирована — экран не прыгает.

### Вёрстка/логика (zcode)

1. Ячейки кода: автофокус-карусель (ввёл цифру — фокус на следующую, backspace —
   на предыдущую, вставка кода из буфера/авто-подстановка заполняет все).
   **Обязательный hidden-input** с `autocomplete="one-time-code"` +
   `v-maska="'####'"` и v-model на общий код — триггер авто-подстановки
   iOS/Android («Код: {код}», длина 4 — SZ-012 §2.5) не должен сломаться.
2. Устранить наезды: условные блоки свести в статусную зону (п.3 дизайн-части);
   длинные серверные тексты — перенос по словам, центр, без наложения слоёв.
3. Только токены ДС: никаких литералов отступов/шрифтов/цветов
   (`var(--lv-*)`, миксины типографики) — контекст T-019/RES-011.
4. Логику не менять: resend-цикл (аудит 13.09 — честный повтор без ремоунта),
   `EXPECTED_LENGTH = 4`, тексты 429/блокировки от сервера, `confirming`-фидбек.
5. `data-testid` сохранить: `auth-resend-code`, `auth-confirming`,
   `auth-resend-error` (+ поле кода) — E2E не должен сломаться.
6. Единообразие: если правка дешёвая — привести к тому же паттерну экран
   `AuthPhone.vue` (логотип + тот же ритм); если дороже — отдельным срезом этой
   карточки, не расширять скоуп молча.
