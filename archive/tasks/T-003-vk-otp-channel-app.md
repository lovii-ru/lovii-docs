## Цель

Приложение понимает ответ `vk_link_required` и проводит пользователя по флоу:
кнопка «Открыть ВКонтакте» → ввод кода → вход.

## Контекст

1. `lovii_docs`: STATUS → FINDINGS F-035/F-037 → спека §7.2/§7.6.
2. Контракт T-002 (уже в `staging` к моменту старта): ответ `POST /auth/send-code`
   при выбранном канале `vkontakte` без привязки:
   `{ sent: false, vk_link_required: true, vk_deeplink: "https://vk.me/loviiru?ref=<binding_token>", messenger: "vk" }`.
3. Образец реализации — уже работающий Telegram-флоу: `telegram_link_required` +
   `telegram_deeplink` + кнопка-диплинк (см. `src/modules/auth-module/`, обработка
   `telegram_link_required` в API-слое и на экране каналов/ввода кода).

## Шаги

1. **Типы API** (`src/modules/auth-module/api/auth-api.ts`): в ответ send-code добавить
   `vk_link_required?: boolean; vk_deeplink?: string;` — по образцу telegram-полей.
2. **Экран каналов / ввода кода** (компонент с обработкой `telegram_link_required`):
   - для `vk_link_required`: кнопка «Открыть ВКонтакте» (диплинк из ответа —
     использовать как есть, ref-токен внутри) + сразу доступный ввод кода с хинтом
     «Код придёт сообщением от сообщества ЛОВИ в ВКонтакте»;
   - иконка: `IconVk` уже есть в проекте (`src/components/icons/brand-and-logos/`);
   - статус-поллинг НЕ нужен (код доставляется сразу после привязки — контракт T-002).
3. **Ошибки:** `otp_channel_unavailable` для VK — штатное сообщение «канал недоступен,
   выберите другой» (без ретраев).
4. **Тесты** (vitest, по образцу тестов telegram-ветки): парсинг ответа с
   `vk_link_required`, рендер кнопки с диплинком, хинт ввода кода.
5. **Гейты и пуш:** typecheck + vitest 🟢 → пуш в `staging` (НЕ master). Session-док
   `docs/sessions/NNN-vk-otp-channel.md` (следующий номер) + запись в
   `lovii-docs/status.md` в том же пуш-цикле. e2e не трогать.

## Что НЕ делать (стоп-лист)

- НЕ менять e2e-тесты и список каналов по умолчанию (канал приходит с бэка).
- НЕ добавлять новых эндпоинтов и поллинга статуса привязки VK.
- НЕ трогать telegram/max флоу, анти-FOUC, дизайн-систему (кнопка — по канону
  существующих кнопок-диплинков).
