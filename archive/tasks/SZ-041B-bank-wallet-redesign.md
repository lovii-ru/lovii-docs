## 2. Что переоформить в lovii-app

Данные уже живут в API (SZ-040 A-3, zcode): `GET /api/v1/balance` (карты:
личный счёт + компании владельца с ИНН и балансами), `GET /api/v1/balance/entries`
(история проводок с order_id и split_role). Экран: `/profile/wallet`
(`ProfileWallet.vue`, модуль `profile-balance`), вход из профиля — строка «Кошелёк».

1. **Каждый счёт = карта LOVII PAY** со скином из демо: Личный счёт,
   АТМОСФЕРА (ИНН …16839), АКСИОМА (ИНН …23709) — мультикарта (карусель/стопка),
   выбор карты = переключение счёта. Номер карты: BIN 9643 + хвост,
   детерминированный по account_id (генерация номеров — отдельная задача,
   в MVP просто отображение).
2. **История операций** — стиль и фильтры демо (all/пополнения/списания),
   лейблы проводок сохраняются (Выручка точки / Доля компании /
   Вознаграждение представителя/амбассадора · заказ #N).
3. **Уровни PAY/PASS/VIP** — на личной карте (статусная полоска как в демо);
   PASS = активная подписка (Б-3), VIP = оборот (счётчики с A-3, порог 300 000 ₽).
4. «Мои баллы» (балловый контур SZ-039) — привести к той же стилистике
   (карта/секция), не смешивать с рублёвыми счетами.
5. Тёмная тема, responsive (карта ~1.586:1, cqw-номер), PWA — как в демо.

## 5. Отчёт о реализации (Super Z, 2026-09-12, app `03d298a`)

Все 5 пунктов §2 выполнены по эталону демо-сборки 34 (порт канона
css/lovii.css §2 «LOVII PAY — профиль лояльности» в компоненты Vue):

1. **`PayCard.vue`** — 3D-карта: flip по тапу, tilt+блик по курсору
   (только `pointer: fine` и без `prefers-reduced-motion`), чип, золотой
   sheen, номер `9643 xxxx xxxx xxxx` cqw-клампом (fallback vw, контейнер
   `inline-size`), оборот: магнитная полоса + декоративный QR (seed 7 как
   в демо) + CVV-плашка `•••`. Скины канона владельца 2026-09-12: `pay`
   (графит/серебро) · `pass` (ink+розовое свечение) · `vip` (чёрное золото)
   · `biz` (графит/тиффани) — только `var(--lv-*)` + rgba-оверлеи на
   ink-градиенте (прецедент §10 ДС), новых токенов не требуется (снапшот
   v1.11.0 уже содержит `--lv-gradient-ink/gold/pink/tiffany`).
2. **Мультикарта-карусель** (`ProfileWallet.vue`): scroll-snap, выбор счёта
   центрированной картой (rAF-дебаунс) + точки-индикаторы; личный счёт —
   LOVII PAY, компании — LOVII BUSINESS (канон «BUSINESS по умолчанию всем
   МСП», backNote с ИНН). Подсказки демо: «Тап по карте — оборот» +
   «Скопировать номер» (clipboard → toast).
3. **История операций**: табы демо Все/Пополнения/Списания (клиентский
   фильтр: `order_income`/`pool_share` → in; `payout`, adjustment<0 → out),
   группировка по дням «Сегодня / Вчера / дата», строки `.tx-row` с
   иконками-пузырями; лейблы канона сохранены (Выручка точки / Доля
   компании / Вознаграждение представителя/амбассадора · заказ #N).
   Пустые состояния честные (по фильтру / «появятся с первых оплаченных»).
4. **Уровни PAY/PASS/VIP** — статус-карта на личном счёте: полоска-превью
   скинов (клик по уровню = оформление карты, счёт и номер не меняются —
   канон «счёт один»); условия: PAY «базовый», PASS «по подписке»
   (UI-слот, Б-3 не строим), VIP «от 300 000 ₽/мес» (канон 2026-09-12
   вечер). Оборота в /balance нет — прогресс-бар не рисуем (честный ноль).
5. **«Мои баллы»** — секция на кошельке (балл-баланс из /wallet + ссылка
   в `/profile/balance`) + шапка экрана баллов перелицована в язык LOVII
   PAY (ink-карта, золотой блик, монета). Контуры не смешаны.

**Номера карт** (`helpers/pay-card.ts`): BIN `9643 9138` личный / `9643
9142` бизнес, 7 цифр хвоста — детерминированный FNV-1a по account_id
(или ИНН при account_id=null) + контрольная цифра Луна; формат 4-4-4-4.
Генерация/хранение — по-прежнему отдельная задача владельца (§3).

## 6. Правка по ревью владельца (Super Z, 2026-09-12, app `b437392`)

Ревью владельца: «коряво без учёта ширины экрана; зачем-то подписал правила
на фронте». Принято без споров, разобрано и исправлено (детали — FINDINGS
F-041):

1. **Ширина.** Экран не задавал собственных боковых отступов (`.container`
   не паддит — конвенция репо упущена): контент прилипал к краям телефона,
   full-bleed-карусель вылезала за вьюпорт → горизонтальный скролл экрана.
   Исправлено: паддинг страницы по конвенции (`12px 16px calc(var(--lv-
   navbar-offset) + 16px)`); карусель — честный full-bleed, слайд =
   clientWidth без внутреннего паддинга (заодно исправлена snap-математика
   выбора карты, уползавшая на пол-слайда); кошелёк/«Мои баллы» капом 560px
   (на планшете карта больше не гигант); табы фильтров сжаты и не ломаются
   на 320px; баланс на карте не сжимается (`flex-shrink: 0`).
2. **Продукт.** С экрана убраны условия уровней (подписка, порог оборота —
   формулировки канона владельца в §2/§5) и все служебные подсказки («Тап по
   карте — оборот», «Клик по уровню показывает оформление карты…», «счёт и
   номер одни — меняется только оформление»); жаргон «балловый контур» →
   «кэшбэк баллами». Блок уровней переоформлен в продуктовом языке:
   заголовок «Оформление карты» + текущий уровень + сегмент-контрол
   PAY/PASS/VIP с aria-pressed. Превью скинов кликом сохранено — приёмка
   владельца не пострадала.
