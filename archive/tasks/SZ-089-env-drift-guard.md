## Факты (установлены при исполнении P0-волны)

1. **Потеря значений**: в `/opt/lovii-core-staging/.env` (после правок 05.10)
   `TBANK_TERMINAL_KEY/PASSWORD` пусты; в `.env.bak-20261005` — заполнены.
   Следствие — `payments_not_configured`, оплата staging лежала (SZ-087).
   Какая операция стёрла — не установлено (волн env 05.10 несколько: maxsplit,
   noproxy, telegram).
2. **Класс проблемы**: контейнер переживает правки `.env` со СТАРЫМ env —
   обнаружено на моке (поднят до правок, `TBANK_TERMINAL_PASSWORD` пуст →
   дефолт `mockpass123`, Init падал «Неверный Token», пока контейнер не
   пересоздан). Аналогичный механизм, вероятно, действовал при потере 05.10:
   правка .env без `up -d` → сервис работает на устаревших значениях.

## Что должно получиться (требование арены, полное)

1. **Env-diff до deploy**: сравнение ожидаемого env (файл `.env` контура) с
   фактическим env каждого контейнера стека. Сравнивать ИМЕНА и хэши/redacted
   значения (никаких секретов в логах/артефактах).
2. **Fail-fast**: расхождение (имя без значения, значение из набора пустых
   ключей, хэш-мисматч) — падение деплой-джобы с понятным выводом: сервис,
   имя переменной, характер расхождения.
3. **Recreate-гарантия**: после изменения env — гарантированное пересоздание
   затронутых сервисов (`docker compose up -d` уже это делает для изменённых
   env_file — проверить, что все стенды поднимаются именно так; запрет «restart
   без recreate» в процедурах).
4. **Post-deploy сверка**: повторный env-diff фактического контейнера против
   ожидаемого; mismatch → пометка деплоя failed.
5. **Rollback**: процедура возврата — предыдущий `.env`-бэкап + `up -d` + повторная
   сверка (по образцу существующих pre-migrate dump/backups в lovii-deploy).
6. **Session-док + тестовый прогон на staging** (специально вносим mismatch —
   джоба должна упасть; снимаем — проходит).

## Критерии приёмки (от арены)

- Джоба падает при искусственном env-drift (демо-прогон на staging).
- Джоба зелёная при совпадении (обычный деплой).
- Секреты не появляются в выводах (проверка redaction).
- Session-док с процедурой rollback.
- Арена подтверждает → **F-5 закрыт, прод-релиз разблокируется**.

## Реализация (черновик, на усмотрение исполнителя)

- Скрипт `infra/env-diff.sh <stack-dir>`: парсит `env_file` из compose-конфига,
  читает `docker inspect` фактических env, сравнивает sha256 по именам.
- Встраивание: шаг в lovii-deploy ДО `up -d` (pre-check) и после (post-check).
- Отчёт: таблица сервис × имя переменной × статус (ok/mismatch/missing).
