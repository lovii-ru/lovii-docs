## О проекте

**LOVII** — SaaS-платформа локального маркетплейса.  
Объединяет малый бизнес (пекарни, цветы, химчистки, кофейни и т.д.) в единой цифровой инфраструктуре.

**Организация:** ООО «Аксиома» — Правообладатель (Правила платформы, лицензионные договоры)  
**Банковский партнёр:** Т-Банк (Мультирасчеты, эквайринг, СБП)  
**Домен:** `app.lovii.ru` (основной), `lovii.ru` (лендинг)

## Модель доходов (Revenue Model)

### Лицензионная модель

Платформа использует лицензионную модель: Лицензиат (торговая точка) платит
лицензионное вознаграждение за доступ к платформе и инфраструктуре.

### Структура расходов с чека клиента

```
┌──────────────────────────────────────────────┐
│              ЧЕК КЛИЕНТА                      │
│              (100%)                           │
└────────────────────┬─────────────────────────┘
                     │
           ┌──────────┼──────────┐
           ▼          ▼          ▼
    ┌──────────┐ ┌────────┐ ┌──────────┐
    │ БАНК     │ │LOVII   │ │ ТОРГОВАЯ │
    │(эквайринг│ │лиценз. │ │  ТОЧКА   │
    │  0,7–3,16%)│ │вознагр.│ │  90%    │
    │          │ │ ~10%   │ │          │
    └──────────┘ └────────┘ └──────────┘
```

> **Точка всегда получает 90%** (фиксировано). Банк забирает 0,7% (СБП) до 3,16% (карта) — в зависимости от способа оплаты. LOVII получает остаток пула (~10% минус эквайринг).

### Перечисление в соответствии с порядком распределения

> Схема перечислений (40/40/20), пороги вывода, условия подписки Представителя — канон в `PARAMS.md` §Перечисление и §Юр.модель.

### Баланс и вывод средств (P0-7)

- **Баланс профиля** — рубли (кэшбэк, вознаграждения Представителям/Амбассадорам).
- **Вывод средств доступен только при активной подписке.** Если подписка не активна — баланс доступен только для оплаты товаров внутри платформы у любого МСП и для оплаты тарифа.
- Условия вывода (ИП/ООО, самозанятые), пороги, комиссии — канон в `PARAMS.md` §Юр.модель.

### Статусы представителя

> Статусы, условия, пороги, подписка — канон в `PARAMS.md` §Представители.

### Пример расчёта (1 торговая точка, тариф БАЗОВЫЙ)

| Параметр | Значение |
|----------|---------|
| Средний чек | 1 200 ₽ |
| Заказов в день | 4 |
| Дней в месяц | 30 |
| **Выручка точки** | **144 000 ₽/мес** |
| Комиссия 10% | 14 400 ₽ |
| Абонентка | 0 ₽ |
| **Общий доход с точки** | **14 400 ₽/мес** |

**Перечисление:**
- Компания (40%): 5 760 ₽
- Представитель (40%): 5 760 ₽
- Амбасадор (20%): 2 880 ₽

| Всего точек | 105 |
| Средняя выручка точки | 144 000 ₽/мес |
| **Выручка всей сети** | **15 120 000 ₽/мес** |
| Комиссия 10% | 1 512 000 ₽ |
| Абонентка | 0 ₽ |
| **Общий доход сети** | **1 512 000 ₽/мес** |

**Перечисление губернатора (40%):** 604 800 ₽/мес

## Архитектура (продакшн)

- **Backend:** микросервисы, Node.js / Go
- **Данные:** PostgreSQL, Redis
- **Frontend:** Vue 3 + Vite + Tailwind CSS (PWA — прогрессивное веб-приложение)
- **Платёжный партнёр:** Т-Банк (Мультирасчёты, номинальный счёт)
