## Терминология

| Термин | Определение |
|:---|:---|
| **Клиент платформы** | МСП — микропредприятие, торговая точка, подключённая к LOVII |
| **Клиент МСП** | Покупатель / пользователь приложения LOVII, делающий заказы |
| **Партнёр платформы** | Амбассадор — обучает и мотивирует представителей, получает 20% от пула |
| **Партнёр амбассадора** | Представитель — подключает торговые точки на локации, получает 40% от пула |
| **Компания** | ООО «Аксиома» / АО «Платформа» — оператор LOVII, получает 40% от пула |
| **ТСП** | Торгово-сервисная точка (синоним: клиент платформы, МСП) |
| **GMV** | Совокупная выручка всех клиентов платформы за период |
| **Нагрузка** | Комиссия, которую клиент МСП платит за каждый заказ (10%) |
| **Take Rate** | Доля дохода платформы от GMV |
| **PRO** | Тарифный план клиентов платформы с абонентской платой 2 990 ₽/мес |

## 1. Резюме

**LOVII** — гибридная платформа (marketplace + SaaS) для микробизнеса: продажи, кэшбэк, лояльность в одном приложении.

| Метрика | Значение |
|:---|:---|
| Базовый юнит | 1 клиент платформы (МСП) |
| Средний чек клиента МСП | 1 200 ₽ |
| Заказов клиента МСП в день | 4 |
| GMV 1 клиента/мес | 144 000 ₽ |
| Take Rate платформы | 7,41% |
| Доход Компании с 1 клиента | 7 258 ₽/мес |
| Точка безубыточности | 500 клиентов платформы (месяц 8) |
| Прогноз на год 5 | 5 000 клиентов, 250,7 млн ₽ доход |

## 4. Все доходные статьи

### 4.1 Транзакционные комиссии (~55% дохода)

```
Доход = GMV × 7,41% × 40%
```

### 4.2 Абонентская плата PRO (~30%)

```
Доход = Кол-во_клиентов_платформы_PRO × 2 990 ₽
Целевая конверсия: 20% (год 1) → 45% (год 5)
```

### 4.3 Комиссия с кэшбэка (~5%)

```
Кэшбэк_сумма = GMV × Доля_клиентов_платформы × Средний_%_кэшбэка
Комиссия = Кэшбэк_сумма × 25%
Доля_Компании = Комиссия × 40%
```

### 4.4 Реклама (~5%)

```
Доход = Рекламодатели × Средний_чек × 30% (через ООО «Мобиап»)
```

### 4.5 Роялти от франшиз (~3%)

```
Доход = GMV_локации × 5–8% (от франшиз)
```

### 4.6 Дополнительные функции (~2%)

```
Доход = Подключения × Стоимость_услуги (продвижение, аналитика)
```

### 4.7 Вывод средств (<1%)

```
Доход = Выплаты × 1% (комиссия банка за переводы)
```

### 4.8 Логистическая маржа (~3%)

```
Доход = Кол-во_доставок × Средняя_стоимость_доставки × Маржа_платформы
Маржа = 15–25% от стоимости доставки

Пример:
  100 доставок/день × 200 ₽ × 20% = 4 000 ₽/день = 120 000 ₽/мес
  Доля Компании (40%) = 48 000 ₽/мес
```

### 4.9 ПВЗ-франшиза (~2%)

```
Вступительный взнос: 50 000 ₽ (единоразово)
Абонентская плата: 2 000 ₽/мес
Операционный доход: 30–50 ₽/заказ

Пример (1 ПВЗ):
  Взнос: 50 000 ₽
  Абонентка: 2 000 ₽/мес
  Операционный: 50 заказов × 40 ₽ = 2 000 ₽/мес
  Итого/мес: 4 000 ₽
```

### Сводная таблица

| № | Статья | Доля | Формула |
|:--|:---|:---|:---|
| 1 | Транзакции | ~50% | GMV × 7,41% × 40% |
| 2 | Абонентка | ~25% | Клиенты_платформы_PRO × 2 990 ₽ |
| 3 | Кэшбэк | ~5% | Кэшбэк × 25% × 40% |
| 4 | Реклама | ~5% | Рекламодатели × ставка |
| 5 | Роялти | ~3% | GMV_локации × 5–8% |
| 6 | Доп. функции | ~2% | Подключения × цена |
| 7 | Вывод средств | <1% | Выплаты × 1% |
| 8 | Логистика | ~3% | Доставки × маржа × 40% |
| 9 | ПВЗ-франшиза | ~2% | Взнос + абонентка + операции |
