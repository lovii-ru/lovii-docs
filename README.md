## Структура нарочно плоская

Чтобы можно было:
- точечно править модули в `as-is/`, не ломая корневые мета-документы;
- добавлять новые категории (`canon/`, `briefs/`, `decisions/`, `archive/`,
  `artifacts/`) как отдельные коммиты — без перетряхивания корня;
- потом одной операцией переносить всё в `archive/` (когда материал устареет).

Шаблон — рабочий `LOVII/lovii_docs/` (`canon/`, `archive/`, `artifacts/`, `public/`).

## Правила

- Факт = `file:line` из среза 2026-09-17; при изменении кода строка обновляется.
- «Как есть» ≠ «как надо»: предложения пишем только в раздел «Кандидаты»
  внутри каждого модуля.
- Числовые параметры (%, суммы, пороги) — ссылкой на канон
  (`/Users/best/LOVII/lovii_docs/canon/PARAMS.md`), без копирования.
