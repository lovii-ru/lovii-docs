# 06 · UI-спецификация

> Экраны кабинета «ЛОВИ Бизнес», клиентские поверхности приложения LOVII и экран кассира. Стиль — текущая PWA LOVII (hash-роутинг, mobile-first, темы light/dark/system, размер текста, отключаемые анимации — как в разделе «Настройки» демо). Дизайн-токены — [LOVII Design System](../lovii-design-system/). Кликабельный прототип конструктора — [`/demo/app/loyalty-constructor/`](../../demo/app/loyalty-constructor/).

Состояния: пусто (первый вход → CTA «С чего начать»), загрузка (скелетоны), ошибка, «нет данных за период».

### 3.2 «С чего начать» `#/biz/loyalty/start`

Четыре крупные карточки-цели: **Поднять чек · Чаще возвращаться · Привлечь новых · Вернуть уснувших** (+ «Распродать вечером», «Продать вперёд» под «Ещё»). Выбор цели → 3 карточки механик с пресетом «под кофейню» и прогнозом «≈ 4 200 ₽/мес». Кнопка «Настроить за 2 минуты».

### 3.3 Мастер настройки `#/biz/loyalty/new/{template}`

Общий каркас: шапка с шагами (1–4), прогресс, кнопки «Назад / Далее», справа (desktop) или снизу (mobile, сворачиваемая панель) — **живой предпросмотр**: карточка для клиента + мини-симуляция чека.

**Шаг 1 · Параметры** — форма из `params_schema` шаблона. Компоненты: слайдер с полем ввода (порог, %), сегментированный контроль (тип награды), выбор категорий/товаров (чипы из каталога точки), степпер (штампы), таблица ступеней (лестница). Под каждым ключевым полем — подсказка: «Ваш средний чек 320 ₽. Рекомендуем 420–500 ₽». Индикатор риска по марже: зелёный/жёлтый/красный.

**Шаг 2 · Аудитория и время** — «Все клиенты / Новые / Постоянные / Уснувшие / Статус PASS·VIP»; расписание: «Всегда» или окна (дни недели чипами + время); даты начала/окончания; тумблер «Контрольная группа 10 % для честной оценки» (вкл. по умолчанию, с пояснением).

**Шаг 3 · Лимиты и бюджет** — «На одного клиента: 1 раз в день», «Бюджет на месяц: 5 000 ₽ (авто-пауза)», «Не начислять сотрудникам» (вкл.). Прогноз: «≈ 70 чеков/мес пересекут порог → ≈ 4 200 ₽».

**Шаг 4 · Предпросмотр и публикация** — карточка клиента (витрина), экран оплаты с прогрессом, пуш-текст (если включён), условия текстом (`content.terms`, редактируемые), симулятор «Чек 420 ₽ → …, чек 740 ₽ → …». Кнопки: «Опубликовать», «Сохранить черновик», «Запланировать с даты».

Валидация: серверная (`compile` → 422 с `details[].path`) отображается у полей; публикация недоступна без PRO для PRO-механик (карточка «Доступно в PRO» с апселлом).

### 3.4 Карточка кампании `#/biz/loyalty/{id}`

Статус-бейдж, кнопки «Пауза / Редактировать / Дублировать / Архив». Блоки: «Эффект» (участники vs контрольная группа: чек, частота; уровень уверенности), «Воронка» (показы подсказки → добавили товар → получили награду), «Стоимость» (скидки, промо-баллы, использовано/сгорело), график по дням, «Версии» (diff параметров), «Условия для клиента».

## 4. Клиентские компоненты

| Компонент | Описание | Состояния |
|---|---|---|
| `OfferBadge` | Бейдж на карточке точки: `+7 % баллами`, `6-й бесплатно`, `−30 % до 21:00` | обычный / с таймером / выполнено (✔) |
| `ThresholdProgress` | Полоса «До подарка осталось 150 ₽» + кнопка «Добавить круассан» | 0–100 %, достигнуто (зелёная, конфетти при `prefers-reduced-motion: no-preference`) |
| `StampCard` | Кружки `●●●●○○`, подпись «ещё 2 до бесплатного капучино» | пусто / прогресс / заполнена («Использовать») |
| `TierChip` | «Silver · до Gold 3 визита» | по уровням |
| `PointsRedeemSlider` | Списание баллов с разбивкой по лотам («сначала спишутся 150 б., сгорающих 29.09») | недоступно (гость) / max |
| `PointsLotList` | Кошелёк: лоты с датами, метка точки, «сгорает через 3 дня» | |
| `CouponCard` | Купон с таймером, точкой, расстоянием, кнопкой «Применить» | активен / истекает < 24 ч / использован |
| `PostPaySheet` | Модалка после оплаты: начисления, штамп, купон от соседей, колесо | |
| `ReferralSheet` | Ссылка, QR, «Марат — ждём первую покупку» | |

Тексты (RU, канон):

| Ситуация | Текст |
|---|---|
| Порог не достигнут | «До +60 баллов осталось 10 ₽» / «Добавьте эспрессо — и получите +60 баллов» |
| Порог достигнут | «+60 баллов ваши» |
| Штампы | «Ещё 1 напиток — и шестой бесплатно» / «Шестой напиток — бесплатно. Использовать?» |
| Начисление | «+60 промо-баллов · до 6 октября» |
| Сгорание | «150 баллов сгорят через 3 дня — потратьте в „Daily“» |
| Win-back | «Мы скучаем: 200 баллов в „Daily“ до воскресенья» |
| Купон соседей | «Подарок от соседей: −15 % на кофе в „Daily“ · 1 мин пешком · до 27.09» |
| Ошибка кода | «Код не подошёл: истёк или уже использован» |

Правила копирайта: короткие фразы, цифры цифрами, «₽» и «б.» без точек внутри, без восклицательных знаков подряд, обращение на «вы» в клиентском интерфейсе (в текущей витрине допускается «ты» — согласовать с гайдом бренда).

## 5. Доступность и производительность

- Все интерактивные элементы ≥ 50×50 px; фокус-кольцо видимо; порядок табуляции = визуальный.
- Прогресс-бары с `role="progressbar"`, `aria-valuenow/max` и текстовым дублем.
- Анимации (штамп, конфетти, колесо) отключаются при `prefers-reduced-motion` и настройке «Анимации: выключены» (SZ-030 в демо).
- Размер текста — уважать настройку приложения (Мелкий / Обычный / Крупный / Большой).
- Мастер работает офлайн для черновика (localStorage), публикация — только онлайн.
- LCP экрана обзора ≤ 2,5 с на 3G; данные KPI — кэш 5 мин.
