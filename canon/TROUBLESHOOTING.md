# TROUBLESHOOTING — диагностика сбоев документации LOVII

> **Назначение:** «я запустил X, и сломалось» → пронумерованный каталог отказов
> с симптомом, причиной, исправлением и проверкой. Файл растёт при обнаружении
> новых сбоев.

---

## Чек-лист запуска / онбординга

1. **Клонировать `lovii_docs`** и перейти в каталог.
2. **`gh auth login`** — нужен доступ к `bestdeejay-design/lovii_docs` (чтение/запись) и `axiiom-ru/lovii` (запись). Без этого ни `sync-public.sh`, ни `fact-guard.sh` не работают.
3. **Проверить синхронизацию без последствий:** `bash scripts/sync-public.sh --dry-run`. Скрипт покажет решения по 4 файлам (`money_flow_public.md`, `Публичная_оферта.md`, `Оферта_присоединения.md`, `README.md`) и не упадёт.
4. **Проверить fact-guard:** `bash fact-guard.sh`. Должен вывести 🟢 0 violations.
5. **Опубликовать канон:** пуш в `main` триггерит CI, либо локально `bash scripts/sync-public.sh --push`.
6. **Проверить публикацию:** GitHub Pages `https://axiiom-ru.github.io/lovii/` + три ссылки из README.
7. **Проверить лог:** `scripts/sync-public.log` (в `.gitignore`, не коммитится).

## Публикация (sync-public.sh + CI)

### E1 — Публикация не происходит: `gh` не авторизован

- **Симптом:** в логе `ПРОПУСК (ошибка загрузки): docs/...` по каждому файлу; скрипт падает на первом `gh api`.
- **Причина:** `fetch_published()` вызывает `gh api repos/axiiom-ru/lovii/contents/...`. Без `GH_TOKEN` (локально) или `secrets.PAT` (в CI) вызов возвращает ошибку.
- **Исправление:** локально `gh auth login && export GH_TOKEN=$(gh auth token)`; в CI — секрет `PAT` с `contents: read/write` на оба репозитория.
- **Проверка:** `gh api repos/axiiom-ru/lovii/contents/docs/money_flow_public.md --jq '.sha'` возвращает sha, не ошибку.

### E2 — Документ отредактирован, но публичная копия не обновилась

- **Симптом:** правка запушена, а на GitHub Pages старая версия. В логе `ПРОПУСК ... версия ниже опубликованной` или `БЕЗ ИЗМЕНЕНИЙ`.
- **Причина А:** защита от понижения — `ver_cmp` сравнивает версии, и если в источнике версия ниже опубликованной, скрипт намеренно пропускает.
- **Причина Б:** пустая версия — `extract_version` ищет строго `| **Версия** | X.Y.Z |`. Если формат изменился, версия = `0.0.0` → пропуск.
- **Исправление:** вернуть строке версии канонический вид; убедиться, что версия не ниже опубликованной.
- **Проверка:** `bash scripts/sync-public.sh --dry-run` — строка `версия X > опубл.Y → публикуем`.

### E3 — Скрипт падает до публикации (set -e + pipefail)

- **Симптом:** `sync-public.sh` завершается с ненулевым кодом; в логе нет `=== синхронизация завершена ===`.
- **Причина:** `set -euo pipefail` + `extract_version` построен как `grep | grep | head`. Если у документа нет строки версии в нужном формате, `grep` возвращает 1 → скрипт прерывается.
- **Исправление:** привести строку версии к формату `| **Версия** | X.Y.Z |`, либо добавить `|| true` в `extract_version`.
- **Проверка:** `bash scripts/sync-public.sh --dry-run` доходит до финальной строки.

### E4 — Публичные ссылки в README ведут на 404

- **Симптом:** ссылки `https://axiiom-ru.github.io/lovii/docs/Публичная_оферта.html` — 404.
- **Причина:** `.nojekyll` в `axiiom-ru/lovii` отключает Jekyll, `.md` отдаются «как есть», ссылки с `.html` не резолвятся. Или кодировка кириллических имён.
- **Исправление:** проверить `.nojekyll` в `axiiom-ru/lovii`; при необходимости генерировать `.html` или править ссылки на raw-`.md`.
- **Проверка:** `curl -I` по каждой ссылке возвращает `200`.

### E5 — compare.html не строит сравнение версий

- **Симптом:** инструмент сравнения пуст или падает при загрузке тегов.
- **Причина:** `compare.html` читает теги версий из `axiiom-ru/lovii` через GitHub API + jsDelivr. Если тегов нет, инструмент не находит снепшоты.
- **Исправление:** завести теги версий в `axiiom-ru/lovii` при каждой публикации, либо переписать на чтение истории файла (commits) вместо тегов.
- **Проверка:** открыть `compare.html` — выпадают выбираемые версии.

### E6 — Конфликт параллельных пушей (409 при PUT)

- **Симптом:** ошибка `gh api ... --method PUT` (код 409 / sha mismatch), файл не опубликован.
- **Причина:** два пуша в `main` почти одновременно, оба читают один sha, первый PUT проходит, второй получает 409.
- **Исправление:** `concurrency` в workflow уже настроен. При ошибках — повтор PUT с перечитыванием sha.
- **Проверка:** параллельные пуши не оставляют файл неопубликованным.

## Fact-guard (scripts/fact-guard.sh + CI)

### F1 — fact-guard падает: скрипт не найден

- **Симптом:** `bash fact-guard.sh` → `No such file or directory`.
- **Причина:** скрипт位于仓库 корне, не в `scripts/`.
- **Исправление:** `bash fact-guard.sh` из корня репозитория.

### F2 — fact-guard показывает violations

- **Симптом:** вывод начинается с 🔴 и содержит список нарушений.
- **Причина:** числовые параметры скопированы в документ, не являющийся каноном или white-list.
- **Исправление:** заменить копию ссылкой на канон (`PARAMS.md §N`) или добавить файл в `fact-guard.sh` white-list (только если копия осознанна).
- **Проверка:** `bash fact-guard.sh` → 🟢 0 violations.

### F3 — fact-guard не триггерится в CI

- **Симптом:** PR прошёл без проверки fact-guard.
- **Причина:** workflow `.github/workflows/fact-guard.yml` не запускается (проблема с триггером или файлами).
- **Исправление:** проверить `on: pull_request` в `.github/workflows/fact-guard.yml`.
- **Проверка:** создать тестовый PR — fact-guard должен запуститься.

## Быстрая диагностика

```bash
# 1. Синхронизация без последствий
bash scripts/sync-public.sh --dry-run

# 2. Fact-guard — чисто?
bash fact-guard.sh

# 3. Доступен ли публичный репозиторий?
gh api repos/axiiom-ru/lovii/contents/docs/money_flow_public.md --jq '.sha'

# 4. Есть ли строка версии в нужном формате?
grep -nE '\| \*\*Версия\*\* \| [0-9]+\.[0-9]+' canon/*.md

# 5. Живы ли публичные ссылки?
curl -I https://axiiom-ru.github.io/lovii/docs/money_flow_public.html
```
