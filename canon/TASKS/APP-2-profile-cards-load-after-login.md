# APP-2 — профиль: «Не удалось загрузить карты» после входа без перезагрузки

> Открыт 09.10 (session 152 lovii-app, находка полного прохода). P2.
> Реализация 09.10, lovii-app.

## Факт (диагностика живьём)

`loadCards()` вызывается один раз в `onMounted` ProfileModule. Вход происходит
БЕЗ перемонтирования: роут `/profile` тот же, гость → authed, гарда просто
переключает ветку шаблона. Первый запрос /balance ушёл в guest-состоянии
(401 unauthenticated — подтверждено access-логом core), `cardsFailed` остался
`true` навсегда — до перезагрузки страницы. После reload всегда 200.

## Решение

`watch(profileStore.authState)`: переход в `authed` (не с `pending` — холодный
старт уже покрыт onMounted) перезапускает `loadCards()`.
