# SZ-057 — Подписка по приглашению: гейт по промокоду + личный код за подписку

> Статус: **На приёмке** (2026-09-18 zcode; «го» исполнено 19.09 — в staging,
> core cc4e18d / app 39199d6, CI 🟢; живая приёмка владельца)
> Репо: `lovii-core` + `lovii-app` (вертикаль одним агентом)
> Решения владельца (диалог 18.09, ночь):
> 1. Подписка доступна ТОЛЬКО профилям с промокодом в профиле (привязка при
>    регистрации); без него функционал недоступен.
> 2. При подписке генерируется личный промокод — им приглашают МСП,
>    пользователей и представителей в свою структуру; вознаграждения — через
>    существующий пул (SZ-038, EC-11), новых контуров не заводить.
> 3. Хранилище промокода — localStorage (владелец отдал решение ведущему);
>    канал T-010 не тронут.
> 4. Фидбек: новые компоненты не плодить — переиспользовать существующие
>    (отдельный PassSubscription.vue удалён, подписка встроена в блок
>    «Статус LOVII PAY»).

## Что сделано

- **core** (`feat/sz057-promo-subscription`, commit e9453bd+):
  - `activate()`: без привязанного `users.promo_code` (и без собственного
    активного кода) — 403 `subscription_requires_promo`, подписка/проводки не
    создаются;
  - при успешной активации выдаётся личный промокод
    (`RepresentativePromoService`, BRD §3.2: префикс = ветка пригласившего,
    суффикс случайный; ветки нет — фолбэк `AA` Основателя; один активный код,
    возобновления его не меняют);
  - довыдача при успешном продлении в кроне (для подписчиков, оформившихся
    до SZ-057);
  - `UserProfileResource`: + `promo_code` (личный активный) и `inviter_code`
    (код пригласившего). Канон «не светить промокод в профиле» заменён
    решением владельца, сторож-тест переписан;
  - тесты: 4 сценария активации + профиль; preflight 🟢 (pint/rector/phpstan/
    pest-vs-базлайн).
- **app** (`feat/sz057-promo-subscription`):
  - удалён `PassSubscription.vue` (фидбек владельца про лишние компоненты);
  - блок «Статус LOVII PAY» (существующий `ProfileCollapse` в ProfileModule):
    - есть приглашение, подписки нет → CTA «Подключить LOVII PASS» + условия
      (599/199, внутренний счёт);
    - подписан → чип личного кода + «Код»/«Ссылка» (копирование,
      `buildReferralUrl`) + «Подписка активна — до {дата}»;
    - без промокода → строка «Подписка — по приглашению», кнопки нет;
    - после активации `loadProfileInfo()` — код на экране сразу;
  - кошелёк: только отражение уровня (бейдж, скин карты);
  - тесты: 4 сценария ProfileModule + 2 кошелька; `yarn test` 🟢 целиком.
