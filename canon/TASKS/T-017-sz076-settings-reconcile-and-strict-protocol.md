### Фаза Г — Строгий регламент исполнения (обязателен для этой и всех следующих задач кабинета МСП)

Каждый шаг zcode обязан:

1. **Локально.** Работа — в worktree (как session 129: `lovii-app-sz074`), `yarn dev` на
   `localhost:5173`, API — staging. На сервер/env/секреты — **не лезть** без отдельной
   карточки и разрешения владельца. **Запретные зоны** (WORK_PROTOCOL §1.2) — только zcode
   по своей карточке: `config/payments.php`, платёжные домены/экшены, `tbank-mock`,
   `ProfileWallet`/`PayCard` балансы, чарджбэк-контур `SZ-045`/`F-050`. В этой карточке
   запретные зоны не трогаются даже «попутно».

2. **Тесты обязательны.** Перед каждым коммитом: `yarn test` (format → lint → unit →
   type-check → build + DS-guard) — зелёный. Playwright-спеки — для экранов. Без зелёного
   коммит не идёт.

3. **Зелёный с первого раза.** Запрет на серии «фикс-пушей»: один логический пакет = один
   push (WORK_PROTOCOL §9.3). Перед пушем — все локальные гейты зелёные, чтобы CI GitHub
   был зелёным с первого прогона. Если CI упал — **стоп**, фикс локально, новый коммит в
   тот же пакет, потом один push. Серии «красный → фикс-пуш → красный → фикс-пуш» —
   запрещены (бот-паттерн, WORK_PROTOCOL §9.2).

4. **Коммит на каждый шаг.** Гранулярные коммиты (не один большой): один экран / одна
   правка = один коммит, conventional message со ссылкой `SZ-xxx` и/или `T-017`.

5. **Session-док на каждый шаг.** В `lovii-app/docs/sessions/NNN-<topic>.md` — что сделано,
   какие коммиты, тесты, скрины, отклонения. Номер сессии — следующий свободный
   (132 занят ретро-доком по Настройкам, 133+ — новые шаги).

6. **Артефакты в каноне.** Карточка `canon/TASKS/T-NNN` — статус, отчёт, приёмки.
   Session-док — в репо (`docs/sessions/`). Скрины/спеки — в `artifacts/`. **Ничего не
   оставлять только в чате или worktree** — это и есть корень «потеряшек», который чинит
   эта карточка.
