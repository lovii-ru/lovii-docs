# SZ-086 — Маска телефона на входе съедает последнюю цифру + дубль пользователей

> Статус: **Открыта**
> Приоритет: **P0** (прямая потеря новых пользователей: аккаунт заводится на
> несуществующий номер, OTP уходит мимо)
> Источник: проход стендов как пользователь 2026-10-06
> (`workspace/TASK-2026-10-06-STAND-WALKTHROUGH.md`, находка 1)
> Репо: `lovii-app` (маска/экран входа), `lovii-core` (нормализация phone)
> Дата постановки: 2026-10-06

## Факт (воспроизведено живым проходом на staging)

1. Экран входа: пользователь вводит номер **с ведущей 7/8** (как обычно,
   11 цифр: `79009990123`) → маска показывает `+7 790 099 901 2`, последняя
   цифра **3 молча теряется**. Регистрация создаёт пользователя с телефоном
   `+77900999012` (staging user id 3).
2. Тот же номер через API (`send-code`/`confirm` с нормальным форматом
   `+79009990123`) создаёт **второго** пользователя (staging user id 4) —
   нормализации между UI- и API-путями нет; «профиль = номер» нарушен.
3. Отображение в кабинете staging при этом усечённое (`+7 790 099 9012`,
   `+7 791 192 8747` у владельца) при корректном номере в БД — на проде тот же
   профиль отображается верно (`+7 911 928 74 78`): сверить бандл staging
   (8924ee4) и данные копии 04.10.

## Что должно получиться

1. Маска принимает 11 цифр с ведущей 7/8 и **не теряет цифры** (ведущую 7/8
   съедает как код страны, а не как часть номера); ввод 10 цифр после `+7`
   — как сейчас.
2. Бэкенд нормализует phone до единого канонического вида на ВСЕХ путях
   (UI-регистрация, API send-code/confirm) — повторный вход по тому же
   номеру находит того же пользователя, дублей нет.
3. Отображение телефона в кабинете/кошельке/чекауте соответствует канону
   `+7 XXX XXX-XX-XX` и на staging.
4. Миграция/склейка: существующие усечённые дубли (staging user 3/4 —
   репродукция, можно удалить) — правилом склейки для реальных данных.

## Критерий приёмки

- Ввод `79009990123` и `89009990123` и `9009990123` на экране входа → один и
  тот же профиль; код доставляется; в БД один user.
- Прогон по кабинету staging: формат телефона верный во всех 3 местах
  (профиль, кошелёк, чекаут).
- Гейты репо зелёные; unit на маску/нормализацию.
