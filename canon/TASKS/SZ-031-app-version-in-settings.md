# SZ-031 — Версия сборки в настройках приложения

> Статус: **На приёмке** (2026-09-11, Super Z — отчёт §5; приёмка
> zcode + владельца запрашивается). Постановка (2026-09-10, zcode по запросу владельца — пачка
> улучшений настроек)
> Приоритет: **P2** — мелочь, но сразу поднимает поддержку: «какая у вас
> версия?» answered одним взглядом
> Исполнитель: Super Z · Репо: `lovii-app` · Гейт: `yarn test`
> База: session 022 (настройки нижним шитом уже live на staging)

## 1. Контекст

Шит «Настройки» (`SettingsSheet.vue`) жив; внизу сейчас только подсказка
про «Системную». `package.json` = `0.0.0` — бесполезен. Владелец и
поддержка не могут отличить сборку staging от будущей прод без DevTools.

## 2. Задача

- **Автоинъекция при сборке** (никаких ручных бампов): в `vite.config.ts`
  define `__APP_VERSION__` из git — короткий SHA + ветка/дата сборки,
  например `staging·4e3ff9c·2026-09-10`. Производная от `git describe`/rev-parse
  на момент build (CI собирает в checkout репо — SHA доступен).
- **UI**: строка-подпись внизу шита, `caption`, tertiary-цвет:
  «Лови · версия {__APP_VERSION__}». Тап по строке копирует версию в
  буфер (с ненавязчивым подтверждением «Скопировано», без alert).
- В типах (`vite-env.d.ts` или аналог) объявить глобал, чтобы type-check
  проходил.

## 3. Ожидаемый конечный результат (приёмка zcode)

1. На app-staging в шите настроек видна версия, соответствующая последнему
   задеплоенному коммиту staging (сверяю `git log origin/staging -1` ↔ строка).
2. Локальная dev-сборка показывает своё значение (dev SHA/hash без падений —
   короткий SHA недоступен в редких кейсах → фолбэк `dev`, не краш).
3. Тап копирует версию (проверка в IAB).
4. Юнит-тест: строка рендерится; `yarn test` 🟢 (type-check включительно).
5. Прод-поток не тронут: деплой-воркфлоу меняется минимально (define
   считается в vite.config на этапе build, а не в CI-скриптах).

## 4. Приёмка владельца

Открыл настройки на стенде — видит версию; прод в будущем отличается от
staging на глаз.


## 5. Отчёт исполнителя (Super Z, 2026-09-11)

- `vite.config.ts`: define `__APP_VERSION__` — автоинъекция на билде из git
  (`branch·sha·date`, напр. «staging·38cba47·2026-09-11»), fallback
  «dev/local» вне git; никаких ручных бампов. `env.d.ts`: declare const.
- SettingsSheet: строка-подпись внизу шита «Лови · версия …» (caption,
  tertiary); тап копирует сырую строку версии в буфер («Скопировано» 2с,
  без alert); clipboard недоступен — просто показываем.
- Тесты: +2 sheet (версия видна / копирование с подтверждением); витест
  подтверждает инъекцию (строка реально попадает в компонент). Коммит
  app `1bdf9cd`.
- NB: «Очистить кэш» (SZ-032) была реализована раньше (`0fdf130`) —
  строка версии стоит после неё (внизу шита), порядок honest.
