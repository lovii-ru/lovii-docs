# SZ-052 — Подписка Представителя: домен (модель, статусы, миграции)

> Статус: **В работе** (2026-09-18, исполнитель zcode)
> Приоритет: **P1** (блокер пилота M1 — без подписки не работает гейт выплат
> PARAMS §1.6 и тариф 599/199)
> Репо: `lovii-core`
> Источник: `lovii-docs/BACKLOG_REVIEW.md` §A2, **часть 1 из 3**
> (далее: SZ-053 sub-billing — каскад/retry/grace-cron; sub-price-lock — P2)

## Решения владельца (17.09, §A2 + §C2)

| Параметр | Решение |
|---|---|
| Стоимость | 599 ₽/мес; по акции 199 ₽/мес (промокод Амбассадора) |
| Единица учёта | Календарная дата (период = календарный месяц) |
| Price Lock | 199 ₽ фиксируется за пользователем на весь срок владения статусом |
| Каскад списания | LOVII Business → LOVII PAY → внешняя карта |
| Grace period | 48 ч; статус НЕ сбрасывается, вознаграждения начисляются |
| Retry | Каждые 6 ч, первая попытка 09:00 МСК |
| Аннулирование | 48 ч без оплаты → suspended, акционная цена сбрасывается |

## Что сделать (эта карточка)

1. Миграция `subscriptions` (одна подписка на профиль, уникальный `user_id`,
   снимок цены в копейках, календарный период, окно grace) +
   `subscription_status_changes` (append-only история переходов, зеркало
   ledger-стиля).
2. Enum `SubscriptionStatus` (active / grace_period / suspended / cancelled)
   с картой допустимых переходов и гейтом `grantsBenefits()` — «в grace статус
   не сбрасывается, вознаграждения начисляются» (§A2).
3. Модель `Subscription` + машина переходов `SubscriptionStatusMachine`
   (единственная точка смены статуса, стиль `OrderStatusMachine`: guard +
   история в одной транзакции).
4. Конфиг `config/subscription.php` — цены 59900/19900 коп., grace 48 ч,
   retry 6 ч (параметры для №3, здесь только значения).
5. Read-API `GET /api/v1/subscription` — честное состояние: нет подписки →
   `data: null`.

## Что НЕ делать (здесь)

- Каскад списания Business → PAY → внешняя карта, cron retry 09:00 МСК,
  авто-переходы по времени — **№3 sub-billing**.
- Логика Price Lock (фиксация 199 ₽ за пользователем) — **P2** (модель уже
  несёт снимок цены и источник `standard|promo`).
- Гейт выплат «только при активной подписке» (PARAMS §1.6) — в задаче выплат
  (№4), применит `SubscriptionStatus::grantsBenefits()`.
