# SZ-030 — «Уменьшить анимации» в настройках приложения (доступность)

> Статус: **На приёмке** (2026-09-11, Super Z — отчёт §5; приёмка
> zcode + владельца запрашивается). Постановка (2026-09-10, zcode по запросу владельца: «идеи хорошие,
> не откладывать» — пачка улучшений настроек)
> Приоритет: **P1** — доступность: части пользователей анимации физически
> некомфортны (вестибулярная чувствительность), у кого-то — слабое устройство
> Исполнитель: Super Z · Репо: `lovii-app` · Гейт: `yarn test`
> База: session 022 (настройки нижним шитом уже live на staging)

## 1. Контекст

В профиле теперь шит «Настройки» (`SettingsSheet.vue`) с темой
(Системная/Светлая/Тёмная) и размером текста. Движение в UI сегодня
везде: переходы шитов, скелетоны, transitions строк/кнопок,
`scroll-behavior: smooth`. Системную опцию `prefers-reduced-motion`
приложение сейчас игнорирует.

## 2. Задача

Третья настройка в шите — «Анимации», тот же паттерн карточек-радио, что
тема (код шита уже в staging, app session 022):

- **Системные** (дефолт) — следовать `prefers-reduced-motion` live, как тема
  следует `prefers-color-scheme`;
- **Включены** — полная анимация всегда;
- **Выключены** — движение минимизировано всегда.

Механика:
- ключ `loviiMotion` (`system|on|off`) в localStorage, применение до маунта
  приложения (boot-хелпер рядом с `font-scale.ts`; анти-FOUC не нужен —
  вспышки движения не видно, достаточно синхронного apply в `main.ts`);
- носитель состояния — атрибут на `<html>` (например `data-motion="off"`),
  глобальный CSS-гейт: transition/animation-длительности ~0, шаг анимации
  скелетонов останавливается, `scroll-behavior: auto`;
- «Системные» = реактивное следование через matchMedia-вотчер
  (по образцу `color-mode.ts`);
- подсказка в шите — одна строка, в стиле существующей.

## 3. Ожидаемый конечный результат (приёмка zcode)

1. В шите «Настройки» три карточки «Анимации»; выбор применяется мгновенно
   и переживает перезагрузку.
2. «Выключены»: шит открывается/закрывается без анимации (контент не
   «прыгает» — появление мгновенное), скелетоны статичны, строки без
   transition. Приложение остаётся полностью рабочим — ничего не ломается
   без анимаций.
3. «Системные»: в DevTools (эмуляция reduced motion) поведение соответствует.
4. Юнит-тесты: три опции, персист, применение атрибута; `yarn test` 🟢.
5. Паттерн кода — как у темы: один хелпер-источник истины, никаких локальных
   `document.documentElement` записей из компонентов мимо него.

## 4. Приёмка владельца

Профиль → Настройки → «Выключены» → всё мгновенно, глаз не «цепляется»;
включил обратно — анимации вернулись.


## 5. Отчёт исполнителя (Super Z, 2026-09-11)

- `motion.ts`: system|on|off, ключ `loviiMotion`, атрибут `data-motion` на
  <html>; «Системные» — один глобальный matchMedia-вотчер (singleton, по
  образцу color-mode.ts), реактивно пересобирает атрибут при смене
  prefers-reduced-motion; синхронный apply в main.ts до монтирования.
- `normalize.scss`: миксин lv-motion-gate (transition/animation 0.01ms,
  iteration-count 1, scroll-behavior auto) — включается media-запросом ИЛИ
  `html[data-motion="off"]`; скелетоны застывают, шит появляется мгновенно.
- SettingsSheet: секция «Анимации» — три карточки-радио (паттерн темы),
  testid `settings-motion-*`, подсказка одной строкой.
- Тесты: +7 unit (motion.ts) +3 sheet (опции/дефолт; off → атрибут+персист;
  on поверх системного reduce); полный прогон 359/359; vue-tsc/oxlint/eslint
  чисты. Коммиты: app `734c7d9` + `142dd0c`.
