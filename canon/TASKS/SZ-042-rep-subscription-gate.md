# SZ-042 — Подписка представителя 599/199 ₽ + гейт доли (Б-3)

> Статус: **Открыта** (zcode, 2026-09-12; остаток финконтура после SZ-041)
> Приоритет: **P1** — без неё 40% не имеют гейта и подписка не продаётся
> Исполнитель: **Super Z** · Репо: `lovii-core` + `lovii-app` ·
> Гейт: `docker exec lovii-core-app-1 composer test` / `yarn test`
> Источники: FIN_BALANCE_REFERRAL_BRIEF Б-3, BRD §4.6 (599/199 — 100% Компании,
> вне сплита), SZ-038 фаза 1 (roles/promo, `rep_subscription_gate` слот уже
> зарезервирован в конфиге сплита), SZ-040 (ledger).

## 1. Факт

- Представитель определяется активным промокодом (SZ-038 фаза 1,
  `representative_promo_codes`); поля подписки/гейта ещё нет.
- В конфиге сплита SZ-040 зарезервирован флаг
  `payments.split.rep_subscription_gate` — при включении доля 40% у
  представителя с неактивной подпиской уходит Компании.
- Кабинет репа в app готов (SZ-038 фаза 2) — есть куда встроить экран подписки.

## 2. Что сделать

1. **core — модель подписки**: миграция (user_id, plan: 599/199, period_start/
   period_end, status, tbank_payment_id) + resolve-сервис «подписка активна?»
   (учёт grace-периода 🔶-2). Гейт доли: при расчёте сплита SZ-040 проверять
   активность подписки владельца промокода точки; неактивна → 40% → Компания
   (флаг `rep_subscription_gate`).
2. **core — оплата подписки**: POST /representative/subscription/pay через
   T-Bank EACQ (Init в app, образец — оплата заказа; рекуррентность НЕ делать
   в MVP — продление вручную/по ссылке).
3. **app — экран «Подписка» в кабинете представителя**: статус (активна до …),
   тарифы 599/199 ₽, кнопка оплаты, после возврата с эквайринга — обновление.
4. Право «599 vs 199» и продление — по канону BRD §4.6; смену тарифа не
   автоматизировать.

## 3. Приёмка

- Реп с истёкшей подпиской: сплит уходит Компании (проверка инвариантом
  ledger на тестовом заказе); после оплаты 599 ₽ доля снова репу.
- Гейты зелёные; SZ-040 инвариант не задет.

## 4. 🔶 Открытое (владельцу, не блокирует)

1. Grace-период после истечения (сколько дней доля ещё капает?).
2. Канал напоминаний об истечении (пуш/письмо/бот).
