> их не видно)
> Исполнитель: **Super Z** · Репо: `lovii-core` + `lovii-app` ·
> Гейт: `docker exec lovii-core-app-1 composer test` / `yarn test`
> Источники: FIN_BALANCE_REFERRAL_BRIEF A-3/A-4, SZ-040 (ledger + accounts уже

> профиль» корректируется решением владельца: балансы РАЗДЕЛЬНЫЕ — личный +
> счёт каждого юрлица (по ИНН).

## 1. Факт (staging, проверено zcode 2026-09-12)

- Ledger/accounts живы (SZ-040): начисления при CONFIRMED-платеже — 90% чека на
  счёт ИНН компании точки, пул 10%−fee → 40/40/20; заказ #143 инвариант ✓.
- У владельца (user 51) ТРИ сущности: личный профиль + партнёрства
  АТМОСФЕРА (ИНН 7842216839, мерчант+филиал 1024) и АКСИОМА (ИНН 7842223709,
  мерчанта нет) — обе verified. Ещё есть тестовый «Grand» (черновик без
  verified_at) — его в балансах не показывать.
- В app сейчас виден только балловый кошелёк («Мои баллы», SZ-039); рублёвых
  балансов в UI нет.

## 2. Что сделать

1. **core — API балансов**: `GET /api/v1/wallet/accounts` (auth):
   личный счёт пользователя + счёт каждого юрлица, где пользователь —
   владелец/участник партнёрства (мост partner_users.core_user_id →
   partners → merchant/branch → ИНН). Формат: `{accounts: [{type: personal|
   company, label, inn?, balance: {amount, currency}}]}`; суммы в копейках
   (платформенная конвенция). Черновики без `verified_at` не включать.
2. **core — выписка**: расширение `GET /wallet/transactions` (или sibling
   endpoint) фильтром `account_id`, чтобы по каждому счёту видеть историю
   начислений (ledger_entries).
3. **app — экран «Балансы»**: в профиле пункт рядом с «Мои баллы» (или
   объединить: «Кошельки»). Три карточки балансов + история по выбору счёта.
   Пустые балансы = честные нули.
4. Начисления уже пишутся SZ-040 — новых проводок не добавлять, задача ТОЛЬКО
   про читаемый API и UI.

## 3. Приёмка

- Владелец в app видит 3 баланса: личный + АТМОСФЕРА + АКСИОМА; история по
  счёту ИНН АТМОСФЕРЫ показывает 90%-проводку от его тестового заказа.
- Гейты обоих репо зелёные; SZ-040-инвариант (сумма проводок = чек −fee)
  не задет.
