## Контекст

`ProfileTransfer.vue` (staging c797f9e) написан под эталон витрины `lovii-demo/
js/transfer.js`, но визуально отходит от канона ДС «Лови»:

- **Нативный `<select>` «Откуда»** — не соответствует канону контрола выбора ДС
  (у ДС есть свой паттерн селектора/чипов; нативный select рендерится
  по-разному на iOS/Android и не имеет токенов ДС);
- **Отступы на локальных стилях**, не через токены/примитивы ДС: смешение
  `--lv-pad-x`, локальных `14px/12px`, двойные паддинги (контейнер + карточка
  баланса), вертикальные разрывы не по `--lv-block-gap`;
- Вёрстка не проходила T-019 (трансферы уже частично поправлены в T-019 Фаза Г
  — `--lv-pad-x/font-scale`, но карточка баланса, селект, правила и экран
  успеха остались на локальной геометрии).

## Что сделать

1. **Селектор «Откуда»** → канон ДС: нативный `<select>` заменить на контрол
   канона (как у существующих селекторов app — Merchant/BranchSwitcher паттерн:
   карточка-кнопка + дровер-список, либо канонный `AppSelect`, если уже есть в
   `src/components/Ui/`). Одинаковый вид на iOS/Android, токены ДС.
2. **Отступы** — привести к сетке T-019: боковой инсет `--lv-pad-x`, вертикальные
   разрывы `--lv-block-gap`, карточки на канонном радиусе/бордере, без локальных
   магических чисел там, где есть токен.
3. **Типографика** — все размеры через `var(--font-scale)`, классы типографики ДС.
4. Логику (валидация, quote, режимы) НЕ трогать — только презентация.
5. Продуктовый стандарт `PRODUCT_QUALITY_BAR.md`: три состояния, mobile+web,
   скрин-тест.
