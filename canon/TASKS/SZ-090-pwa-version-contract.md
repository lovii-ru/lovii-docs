# SZ-090: контракт версий PWA (принудительное обновление из приложения и с сервера)

Дата постановки: 2026-10-07 (директива владельца + прод-инцидент «не получилось
загрузить приложение»; ресёрч — `lovii_docs/artifacts/2026-10-07-pwa-stale-shell/`).

## Проблема

После серии деплоев пользователи PWA (app.lovii.ru) застревают на устаревшем
шелле: SW отдает навигации из прекэша, ленивые чанки старой сборки на сервере
удалены → 404 → петля. Сверка версии жила только на экране «Настройки», т.е.
внутри того самого (мёртвого) бандла. Серверного рычага не было.

## Решение (реализовано 07.10, ветка sz090-pwa-version-contract)

Контракт: решение о свежести принимает index.html + сервер, не живой бандл.

- `/version.json` — источник истины версии (nginx: `no-store`);
- инлайн-бут-гейт в index.html (работает на мёртвом бандле): расхождение
  `lovi.shellVersion` ↔ `/version.json` → снос SW+кэшей → reload;
- в приложении: сверка на буте + visibilitychange (`version-gate.ts`);
- SW: network-first для навигаций с офлайн-фолбэком на прекэш;
- chunk-recovery: 2-й подряд фейл чанка → авто-чистка шелла;
- анти-цикл: чистка ≤1 раза в 60 c и один раз на серверную версию.

## Ограничение платформы

Гейт в новом index.html не исполнится у клиента, пока его старый SW отдаёт
старый index.html. Застрявшие расцепляются штатным обновлением SW на следующем
заходе с сетью; подмножество с сорванной установкой SW недостижимо сервером
в принципе (вердикт арены 07.10).
