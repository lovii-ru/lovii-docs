## Идея
Демо проработано по дизайн-системе и «выглядит так, как хочу видеть». Приложение на staging
устроено иначе. Задача — **перенести шкурку демо** на приложение, экран за экраном, не меняя
логику: посмотрел экран демо → натянул → сверил → подправил → следующий.

## Принцип работы (на каждый экран)
1. Снять демо-кадр (Playwright, 390 и 1280) и кадр приложения того же экрана.
2. Перенести разметку/классы экрана на компоненты шкурки (`mini-card`, `row-item`, `seg`,
   `stat-pill`, `f-field`, `paycard`, `home-hero`, `nearby-store`, `cart-summary`, `order-*` …),
   на токенах `lovii-design`. Хардкод цвета/радиуса запрещён (DS-guard).
3. Сверить кадры, поправить расхождения (сетка/отступы/типографика/состояния).
4. Гейт `yarn test` (format/lint/unit/type-check/build + DS-guard) → мерж в `staging` → деплой.
5. Строка в трекере: экран, коммит, скрин-пара, отклонения.

## Общий слой
- `src/scss/demo-skin/` — примитивы шкурки (карточки/строки/пилюли/сегменты/поля/таб-бар/хедер)
  как порт `lovii.css` на токены. Экраны подключают примитивы, не дублируют.
- Для лояльности это уже сделано: `modules/roles-module/msp/loyalty/loyalty.scss` (порт `loyalty.css`).

## Решение владельца (2026-09-24): начинаем с ПРОФИЛЯ

Профиль — самый динамичный раздел, «состоит из множества дизайнов и функций». Задача — привести
в порядок: убрать лишнее, где-то двухколоночный экран, где-то глубже по навигации; динамику
(уровни/баллы/операции) взять из демо. **Скины карт не трогаем** — отдельной задачей.
Нижнее меню — **5 кнопок** (как демо: Главная · Поиск · Корзина · Профиль · Настройки).

### Разбор профиля приложения (`lovii-app`)
| Экран/блок приложения | Что делаем | Эталон демо |
|---|---|---|
| Нижнее меню `components/NavBar.vue` (сейчас **4**) | добавить 5-й пункт «Настройки» | `.app-nav` (5 кнопок) |
| Хаб профиля `profile-module/ProfileModule.vue` | натянуть шкурку (`acct`, `row-item`, `seg`, `stat-pill`), убрать лишнее, на десктопе — 2 колонки | `js/profile.js` |
| Уровни/перки (`tier`) | добавить блок уровней из демо (динамика прогресса) | `tier*` в `profile.js` |
| Кошелёк/баланс `profile-balance/ProfileWallet.vue` | шкурка `wallet/paycard` (**без скинов карт**), операции/история | `js/wallet.js` |
| Операции, переводы | шкурка `history`, `tl-item`, `seg` | `wallet.js` |

| Адреса `profile-addresses/ProfileAddresses.vue` | шкурка `address-item` | `addresses` |
| Редактирование/безопасность `profile-edit/*`, `profile-security/*` | шкурка `f-field`, `row-item`; углубить навигацию | `account.js` |
| Настройки (нет в приложении) | создать экран «Настройки» (тема/район/уведомления/установка) | `js/settings.js` |

### Порядок внутри профиля
1. Нижнее меню 5 пунктов + экран «Настройки» (первый проход).
2. Хаб профиля (шкурка + 2 колонки на десктопе + блок уровней).
3. Кошелёк/баланс/операции/переводы.
4. Заказы, адреса, редактирование/безопасность.
## Рабочий процесс (решение владельца 2026-09-24)

1. Делаем **локально** (`yarn dev` в worktree, адрес `http://localhost:5173`, API — staging).
2. Владелец смотрит локально и **принимает** экран (правки — сразу, hot-reload).
3. **Только после приёмки** — деплой на staging (мерж + CI).

Ничего не мержим и не деплоим до явного «принято» по экрану.
