## 3. Транзакции и пул

| ID | Сценарий | Вход | Ожидаемый результат |
|---|---|---|---|
| TC-019 | Транзакция 1000₽ картой | `amount: 1000, payment_method: "card"` | pool = 68.40₽ (карта: 3.16% с НДС 22%) |
| TC-020 | Транзакция 1000₽ СБП | `amount: 1000, payment_method: "sbp"` | pool = 93.00₽ |
| TC-021 | Транзакция 100₽ картой (маленький чек) | `amount: 100, payment_method: "card"` | bank_commission = 3.49₽ (минимум), pool = 100×0.10 - 3.49 = 6.51₽ |
| TC-022 | Транзакция 100₽ СБП | `amount: 100, payment_method: "sbp"` | pool = 100×0.10 - 0.70 = 9.30₽ |
| TC-023 | T-Pay (без НДС, VAT-free) | `payment_method: "tpay"` | pool = 74.10₽ (T-Pay: 2.59% без НДС) |
| TC-024 | Транзакция с вознаграждением (refund) | status: "refunded" | Обнулить distribution, откатить UdidAccount |

> **НДС (с 01.01.2026, ФЗ №425-ФЗ, договор Т-Банк №МР-08.26/АКС_01):** карты — НДС 22% сверху, эффективная ставка `2.59% + 22% = 3.16%` (на 1000₽: bank ₽ = 31.60, пул 6.84% = 68.40₽). T-Pay и СБП — **без НДС (VAT-free)**: T-Pay `2.59%` (на 1000₽: bank ₽ = 25.90, пул 7.41% = 74.10₽), СБП `0.7%` (на 1000₽: bank ₽ = 7.00, пул 9.3% = 93.00₽). Пул = `10% − эффективная ставка банка`; распределение 40/40/20.
