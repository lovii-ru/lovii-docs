# APP-P-048 — МСП — Товары
- Статус: живая
- Маршрут: `/cabinet/msp/products` · name `MspProducts` (src/router/index.ts:855)
- Тип: вложенная (родитель: группа /cabinet/msp, каркас CabinetLayout)
- Доступ: роль msp; таб в навигации по ability `offer.create` (index.ts:807)
- Назначение: каталог точки: список с поиском, добавление/правка/удаление товара с фото, тумблеры «в продаже»/«на витрине» и управление категориями (T-025).
- Функциональные блоки:
  - #toolbar — строка кнопок «Товар | Категория» (T-025): активная кнопка открывает свою форму на экране, повторный тап закрывает (MspProducts.vue:56–57, 332–360); кнопки не рисуются без точки — POST без неё вернул бы 404 partner_not_found
  - #product-form — название, цена (валидация «числом, например 110»), описание, фото (загрузка `api/v1/msp/uploads`, role file input + ссылка), категория, область применения «Точка / Весь мерчант» (scope branch|merchant — без branch_id товар уровня мерчанта); одна форма на добавление и правку (editingId; MspProducts.vue:292–330)
  - #list — строки с фото, ценой ₽, двумя тумблерами: `is_available` (в продаже) и `is_active` (на витрине) — PATCH возвращает товар, строка меняется на месте без перезагрузки списка (MspProducts.vue:407–421); удаление в два шага (confirmingId, MspProducts.vue:382–401); правка перезаполняет форму
  - #categories — категории мерчанта: добавить, переименовать (строка → поле с сохранением/отменой), удалить («сначала перенеси товары»), тумблер скрытия на точке (`branch-visibility`; MspProducts.vue:201–287)
  - #search — клиентский поиск по названию/описанию (серверного поиска точки нет; MspProducts.vue:161–170)
  - #point-check — есть ли точка, решает `/msp/overview` (пустой merchants = нет точки): список не запрашивается вовсе, честное состояние вместо формы (MspProducts.vue:126–135); branch_id из localStorage валидируется по известным точкам (MspProducts.vue:141–143)
- Состояния: loading (скелетон) / пусто — «Точек пока нет» (noPoint: пустой merchants / isPartnerWithoutBranches / 404), «позиций пока нет» с приглашением формы / ошибки — загрузка списка с «Повторить», actionError над формой («Товар не сохранён», «Фото не загрузилось»), ошибка категорий отдельно от «Категорий пока нет» (categoriesError, MspProducts.vue:198–210)
