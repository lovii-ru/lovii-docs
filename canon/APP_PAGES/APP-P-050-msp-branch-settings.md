# APP-P-050 — МСП — Настройки точки
- Статус: живая
- Маршрут: `/cabinet/msp/settings` · name `MspBranchSettings` (src/router/index.ts:867)
- Тип: вложенная (родитель: группа /cabinet/msp, каркас CabinetLayout)
- Доступ: роль msp; таб «Точка» по ability `branch.update` (index.ts:820–825)
- Назначение: управление точкой: карточка магазина (базовый слой МСП), рабочее состояние (вкл/выкл/пауза), расписание v1 с исключениями, минимальная сумма заказа и зона доставки радиусом (SZ-063/066).
- Функциональные блоки:
  - #merchant — «Магазин — видно клиентам»: название, описание, логотип (загрузка через `api/v1/msp/uploads` с kind=logo → PATCH `api/v1/msp/merchant`); рисуется только когда ядро отдало merchant (hasMerchant; MspBranchSettings.vue:264–270, 810, 859)
  - #branch — имя и адрес точки (поля формы; MspBranchSettings.vue:1081–1112)
  - #state — «Состояние точки» (SZ-063): статус-чип + факт ядра, кнопки Выключить/Включить (`mspSetBranchStatus`) и пауза «до HH:MM» (`mspPauseBranch`) с вариантами срока из `pause_options_minutes` платформы (без хардкода); отмена паузы; ошибка действия — словами из конверта core (getApiErrorMessage); смена состояния не трогает несохранённый ввод формы (applyStateFacts; MspBranchSettings.vue:369–380, 669–699)
  - #schedule — «Расписание работы»: тумблер «Круглосуточно» (при is_24h перечисленные дни — честно показываются как исключения, а не отправляются назад: баг «Свежих Раков», MspBranchSettings.vue:250–344), per-day интервалы с селектами ЧЧ/ММ (локаль-независимые; пустой день = выходной), валидация перевёрнутых интервалов и наложений на клиенте; dates-исключения (праздники из b2b) передаются назад как есть
  - #min-order — минимальная сумма: пусто = «без минимума» (0), живая подсказка «Поднимем до N ₽ — меньше платформа не разрешает» (platform_floor) и «рекомендованный минимальный чек (N ₽)» (platform_default; MspBranchSettings.vue:107–143)
  - #delivery — зона доставки (SZ-066): радиус 300–1000 м (границы из ядра), честная подсказка «зоны нет → доставка не принимает», при b2b-настройке (полигон/несколько зон) — только факты, поля радиуса скрыты (radiusEditable/radiusSource; MspBranchSettings.vue:148–248)
- Состояния: loading (скелетон) / пусто — «Точки пока нет» (data:null; MspBranchSettings.vue:970) / ошибки — ОШИБКА ЧТЕНИЯ блокирует форму (иначе сохранение дефолтов затёрло бы расписание; loadError, MspBranchSettings.vue:68–69, 965), formError над кнопкой, stateError рядом с кнопками состояния, «Сохранено» сбрасывается при любом изменении (touch)
- Зависимости: API `api/v1/msp/branch/settings` GET/PUT/PATCH (roles-api.ts:790–847), `api/v1/msp/merchant` PATCH (:859), `api/v1/msp/uploads` (:723); стор store/msp.store.ts; helpers create-order/order-errors.ts, distance-helpers.ts, money.ts
