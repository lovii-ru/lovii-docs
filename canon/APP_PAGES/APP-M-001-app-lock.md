# APP-M-001 — Блокировка быстрого входа (AppLock)

- Статус: живая
- Открытие: компонент `AppLock` — `modules/profile-security/components/AppLock.vue`; рендерится глобально из `App.vue:124` (`<AppLock v-if="appLocked" />`), import `App.vue:13`
- Родитель: глобальный оверлей (App.vue) — поверх любой APP-P, когда включён быстрый вход и приложение заблокировано
- Назначение: экран блокировки устройства для уже авторизованного пользователя — разблокировка по платформенной биометрии (WebAuthn/Face ID) или ПИН-коду, без повторного полного входа.
- Функциональные блоки:
  - #lock-logo — логотип «Лови» (assets/images/lovii-logo-dark.svg); AppLock.vue:74 (блок template)
  - #pin-keypad — клавиатура ввода ПИН (цифры + ⌫), точечная индикация введённых символов; AppLock.vue:150–190
  - #biometric — кнопка входа по биометрии (показывается при `biometricEnabled` и доступности платформы); AppLock.vue (template, блок биометрии)
  - #sms-fallback — «Войти по SMS»: снимает локальный гейт, ведёт в обычный вход (auth); AppLock.vue:22–25 (комментарий), use-quick-access.ts
- Состояния: заблокировано / неверный ПИН / биометрия недоступна / гейт снят (пользователь авторизован, экран скрыт)
- Зависимости: `useQuickAccess` (composables/use-quick-access.ts — verifyPin, pinLength, biometric), `useProfileStore`; WebAuthn-биометрия платформы
- Переходы: → обычный вход/APP-P-059 (через «Войти по SMS») или обратно на текущую страницу после разблокировки
