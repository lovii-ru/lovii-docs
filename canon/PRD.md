## Goals & non-goals

| Goals (this milestone) | Non-goals (explicitly NOT now) |
|------------------------|--------------------------------|
| Построить КИП (комплексную информационную платформу локальной экономики) как SaaS с агентской схемой расчётов (гл. 52 ГК РФ, номинальный счёт ст. 860.1 ГК РФ) | Собственный банкинг, выпуск карт, кредитование (как у Rappi/Glovo) |
| Дать микробизнесу готовую цифровую инфраструктуру: витрину, каталог, приём заказов, кассу, лояльность | Собственный флот курьеров и dark stores (платформа — SaaS, не доставка) |
| Дать клиентам единую программу лояльности на район (баллы 1:1, кросс-обмен, вывод через СБП) | Собственная картография уровня GrabMaps |
| Реализовать реферальную сеть (Амбассадор → Представитель → МСП) со сплитом 40/40/20 по пулу LOVII | Каскадные многоуровневые выплаты (МЛМ-пирамида) — запрещено решением владельца |
| Масштабироваться по городам через франчайзинговую модель (City Franchise, white-label, гео-изоляция) | Выход за пределы РФ на этом этапе (данные хранятся в РФ) |
| Обеспечить юридическую чистоту: фискализация силами Агента (54-ФЗ), исключение из-под 103-ФЗ | Перепродажа товаров и хранение денег клиентов (платформа — агент, не продавец) |

> **RU:** цели на этот этап vs «сознательно не делаем сейчас» — защита от расползания скоупа.

## Functional requirements

### Area 1: Общая архитектура и ролевая модель (F-01)

- FR-1.1: Система поддерживает 5 ролей: Клиент, Торговая точка (Лицензиат/МСП), Курьер, Цифровой представитель / Мэр / Губернатор, Амбассадор. Роли не взаимоисключающие (один UDID может совмещать МСП + Представитель). → US-16
- FR-1.2: Единый аккаунт (UDID) с переключением роли через профиль; состояние роли хранится в `User.legal_status` (ИП / ООО / Самозанятый) независимо от МЛМ-статуса. → US-16
- FR-1.3: Темизация интерфейса (светлая/тёмная/яркая) и white-label per город (гео-изоляция экземпляра). → US-16
- FR-1.4: Аутентификация по телефону + OTP (SMS/WhatsApp/Telegram); хранение персональных данных в РФ (152-ФЗ). → US-16

### Area 2: Клиентская часть (F-02)

- FR-2.1: Витрина (smart feed шорткатов, Flash Deals, подборки), каталог точек (2-колоночная сетка, пилюли категорий, поиск с debounce), карточка товара. → US-01
- FR-2.2: Оформление заказа (самовывоз/доставка) за время < 3 минут; корзина с +/− и итого. → US-01
- FR-2.3: Программа лояльности: баланс баллов (крупно), история начислений/списаний, QR-код лояльности, избранное. → US-02
- FR-2.4: Вывод баллов в рубли через СБП (1 балл = 1 ₽, баллы не сгорают, ликвидность 100% внутри локации). → US-02
- FR-2.5: Чаевые курьеру/точке в рамках заказа. → US-01

### Area 3: Бизнес-часть / ТСП (F-03)

- FR-3.1: Быстрый онбординг МСП через QR за 5 минут: регистрация, акцепт оферты присоединения, авто-открытие субсчёта в Т-Банке («Мультирасчёты»). → US-03
- FR-3.2: CRUD каталога товаров (цена, активность, стоп-лист), загрузка CSV. → US-03
- FR-3.3: Приём и обработка заказов: статусы Новый → Подтверждён → Готов → Выдан; push/SMS уведомления точке. → US-03
- FR-3.4: Касса: фискализация силами Агента (облачная ККТ «Аксиомы», 54-ФЗ), чек с признаком агента и ИНН точки как Поставщика. → US-05
- FR-3.5: Управление персоналом точки (роли сотрудников, доступы). → US-03
- FR-3.6: Отчёты: выручка по дням/неделям/месяцам, детализация по чекам, уровень сервиса (отмены, время доставки). → US-04

### Area 4: Франчайзи (F-04)

- FR-4.1: Управление точками города-экземпляра из кабинета франчайзи; гео-изоляция данных. → US-10
- FR-4.2: Пункты выдачи (ПВЗ): регистрация, привязка к локации. → US-10
- FR-4.3: Рекламный доход локации распределяется между участниками по правилам домена «Реклама». → US-10

### Area 5: Оператор (F-05)

- FR-5.1: Управление тарифами для МСП (Старт 0 ₽/мес при выручке до 30 000 ₽, Базовый 10%, Про 4–7% + 2 990 ₽/мес; индивидуально — для сетей). → US-09
- FR-5.2: Роялти от франчайзи (пул LOVII минус 60%: 20% Амбассадор, 40% Представитель) и мониторинг экземпляров. → US-09
- FR-5.3: Интеграции (Т-Банк, облачные кассы, ОФД) и дашборд экосистемы. → US-09

### Area 6: Логистика (F-06)

- FR-6.1: Подключение внешних служб доставки (Igoods, Яндекс.Go, Чибис, Атмосфера) через API/партнёрские контракты. → US-11
- FR-6.2: Курьер приглашается оператором по коду; статусы «в пути» / «доставлен» / «проблема»; выплаты курьеру на СБП раз в неделю от 1 000 ₽. → US-11
- FR-6.3: DBS (Delivery by Seller): гипермаркеты (Магнит, Лента, ВкусВилл) доставляют сами, платформа агрегирует. → US-11

### Area 7: Реклама (F-07)

- FR-7.1: Баннеры и таргетинг в приложении (через ООО «Мобиап», агентское вознаграждение 15–50%). → US-12
- FR-7.2: Распределение рекламного дохода между участниками локации по прозрачной формуле. → US-12

### Area 8: Кросс-лояльность (F-08)

- FR-8.1: Конвертер баллов между точками (баллы 1:1, не сгорают). → US-02, US-13
- FR-8.2: Обмен баллов и офлайн-оплата через QR в точке (клиент сканирует QR, списываются баллы/рубли). → US-13
- FR-8.3: Конструктор лояльности МСП: кэшбэк в % и акциях (пятница, самовывоз, подарок). Кэшбэк начисляется только если МСП настроил его; натуральный обмен (подарок) комиссии не несёт. → US-04
- FR-8.4: Комиссия LOVII за начисленный кэшбэк — 25% от суммы кэшбэка; распределяется 40/40/20 (Компания 10% / Представитель 10% / Амбассадор 5% от суммы кэшбэка). → US-04

### Area 9: Финансы и юр. инфраструктура (F-09)

- FR-9.1: Агентская схема (гл. 52 ГК РФ): ООО «Аксиома» — торговый агент (поверенный) Принципала; приём платежей на номинальный счёт (ст. 860.1 ГК РФ) с автоматическим сплитом банком-партнёром (Т-Банк, «Мультирасчёты»). → US-05
- FR-9.2: Маршрутизация платежа: 90% точке, пул LOVII = 10% минус банк-эквайер. Эквайринг: Карта 2,59% + НДС 22% = 3,16% (ФЗ №425-ФЗ с 01.01.2026); T-Pay 2,59% без НДС; СБП 0,7% без НДС. → US-05
- FR-9.3: Консолидатор платежей и поддержка самозанятых (НПД): выплаты по `legal_status`. **Вывод средств доступен только при активной подписке** (иначе баланс — только для оплаты товаров/тарифа внутри платформы). ИП/ООО — push-канал (по графику, без порога, комиссия банка 0,5% платит Компания). Самозанятый — pull-канал (по запросу, порог 3 000 ₽; при ≥ 3 000 ₽ комиссия 1% платит Компания, при < 3 000 ₽ мин. 30 ₽ удерживается из суммы вывода). → US-15
- FR-9.4: UDID-счёт (внутренний рублёвый баланс: копится, тратится, переводится, выводится) и МСП-счёт (обнуляется после выплаты на р/с). → US-02, US-15
- FR-9.5: KYC/AML для вывода средств; соответствие 161-ФЗ, 115-ФЗ, PCI DSS; хранение данных в РФ. → US-15

### Area 10: HR и обучение (F-10)

- FR-10.1: Портал обучения для Представителей/Мэров/Губернаторов; события: Школа (для Представителей, наставники Мэры), Академия (для Мэров, преподаватели Губернаторы), Каникулы (для Губернаторов, за счёт Компании). → US-08
- FR-10.2: Рейтинги, бонусы и корпоративная мотивация (HR-баллы для партнёров вроде Билайн/Неолоджик). → US-08
- FR-10.3: Статус пересчитывается ежедневно в 03:00 МСК; one-way progression (понижение не применяется). → US-08

### Area 11: API (F-11)

- FR-11.1: REST/GraphQL API (`api.lovii.ru/api/v1`), вебхуки, white-label виджет для сторонних сайтов. → US-14
- FR-11.2: Публичные эндпоинты: регистрация, смена промокода, активация подписки, транзакция, кэшбэк, статус, перевод, вывод, события, создание амбассадора. → US-14

### Area 12: Дополнительно (F-12)

- FR-12.1: Локализация интерфейса (RU/EN/CN для корпоративных юрлиц). → US-17
- FR-12.2: Модерация точек и товаров (админка), поддержка. → US-17
- FR-12.3: AI-рекомендации (подборки, акции) на базе ClickHouse-аналитики. → US-18
- FR-12.4: Антифрод-лог: аномальный прирост МСП под одним промокодом, доля чарджбэков, дробление транзакций (бэклог, не блокирует MVP). → US-17

### Area 13: Реферальная система (F-13) — логика из BRD, каноническая

- FR-13.1: Промокод формата `PPXXXX` (6 символов, алфавит 33: `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`, без 0/1/I/O). Префикс (2 символа) = ветка Амбассадора, суффикс (4) уникален в рамках префикса. Ёмкость ~1,29 млрд кодов. → US-06, US-07
- FR-13.2: Регистрация без промокода → префикс `AA` (Основатель). `AAAAAA` зарезервирован навсегда. → US-06
- FR-13.3: Смена промокода не чаще 1 раза в 30 дней; меняется только суффикс, префикс (ветка) сохраняется; прошлые начисления не пересчитываются. → US-06
- FR-13.4: Подписка (базовая 599 ₽/мес, по промокоду Амбассадора 199 ₽/мес) определяет активность промокода. Активна → начисления владельцу; истекла/не оплачена → 40% уходит Компании. → US-06
- FR-13.5: Подписка НЕ входит в сплит 40/40/20 — 100% выручки Компании, не создаёт запись `PoolDistribution`. → US-06
- FR-13.6: **2-уровневая модель (без каскада):** Представитель получает 40% пула только с транзакций точек, зарегистрированных лично по его промокоду (1 уровень). Амбассадор получает 20% пула со всех транзакций ветки (branch-wide). Статусы Мэр/Губернатор не дают дополнительных денежных начислений, только привилегии. → US-06, US-07, US-08
- FR-13.7: Распределение пула 40/40/20 (Компания / Представитель / Амбассадор) считается ТОЛЬКО по регистрационному промокоду МСП (поле `promo_code` от клиента в запросе транзакции игнорируется). → US-06, US-07
- FR-13.8: Проверка активности перед начислением: Представитель — `is_subscription_active`; Амбассадор — `is_active` (не деактивирован Основателем). При неактивности доля уходит Компании. → US-06, US-07
- FR-13.9: Округление всех сумм до копейки (`ROUND_HALF_UP`) на каждом шаге; остаток округления добавляется в долю Компании, так что `company + rep + ambassador == pool` всегда точно. → US-06, US-07
- FR-13.10: Self-referral разрешён: владелец точки, зарегистрировавший свою точку под своим промокодом, получает свои 40% как обычный Представитель. → US-06

## Non-functional requirements

| ID | Aspect | Requirement |
|----|--------|-------------|
| NFR-1 | Performance | Время оформления заказа (клиент) < 3 мин; p95 ответа API < 300 мс |
| NFR-2 | Availability | Доступность платформы 99.9%; выплаты МСП 100% в срок (критерий пилота) |
| NFR-3 | Security | Authn/authz по UDID + OTP; изоляция данных экземпляра города (гео-изоляция); KYC/AML на вывод; PCI DSS при работе с банком-партнёром |
| NFR-4 | Accessibility | WCAG AA для клиентского и бизнес-интерфейсов |
