# SERVER_HYGIENE — гигиена и правила прод-сервера (санитарная)

> Канон для gostiny-prod-01 (прод+staging, один сервер). Секреты — в воркспейсе
> (`PROD-SERVER-AND-MONITORING.md`), здесь — правила. Учреждено после аудита
> 2026-10-18 (`АУДИТ-СЕРВЕРА-2026-10-18.md` в воркспейсе).

## Правила контента сервера

1. **Только проектное.** На проде живут: 8 стендов lovii (4 репо × prod/staging),
   `gateway`, `monitoring`/`lovii-observability`, деплой-раннеры (сейчас
   остановлены — CI на CHUWI). Посторонние проекты (быв. `turok-tv-api`) —
   владелец решает явно; до решения работают, но в каноне помечены как чужие.
2. **Мусор не живёт в /opt.** Экспериментальные директории и остановленные
   контейнеры старше 30 дней — архивировать в `/root/archive-<дата>/` (chmod 600)
   и удалять из рабочего расположения.
3. **Ключи и секреты**: не хранить в /opt «бакапы с секретами»; неиспользуемые
   VPN-ключи удалять (архив). Секреты в cmdline процессов = находка P1.
4. **Секреты**: полнный реестр — в воркспейс-доке; ротация — разовая по факту
   утечки/смены провайдера, не по крону. Ротация = перевыпуск у источника +
   обновление env + рестарт затронутых контейнеров + запись в session-доку.

## Правила сети

5. Исходящие прокси-цепочки держать **включёнными только пока используются**.
   Мёртвый upstream (недоступен >24ч и не нужен ни одному живому пути) — гасить.
6. Экспортеры метрик слушают только localhost; наружу — 80/443 (Caddy) и 22.
7. DPI-блокировки транзита хостера (с 17.10): bunny-CDN блокирован на уровне РФ
   (смирились — сборка без pecl), Telegram/ghcr — у хостера (CI перенесён на
   CHUWI). Возвращать/менять — после ответа хостера на тикет.

## Правила ресурсов

8. **Docker-гигиена раз в квартал или при >70% диска** (порог чистки диска 75%):
   - `docker builder prune -af` (безопасно);
   - `docker image prune -f` (dangling, безопасно);
   - `docker image prune -a` — только с оглядкой: последние 2 образа каждого
     сервиса держать для отката; всё нужное лежит в ghcr, локальное восстанавливаемо;
   - volumes — НЕ чистить автоматически: только по списку после сверки
     (`docker volume ls` + `docker system df -v`), там могут быть данные.
9. Ротация логов контейнеров — daemon.json (10m×5) уже настроена; не отключать.
10. `apt upgrade` + ребут — раз в квартал или по security-рекомендации, в окно
    минимального трафика (ночь), после сверки, что прод-раннеры всё ещё не нужны.
