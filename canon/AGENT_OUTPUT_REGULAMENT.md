# LOVII — регламент сохранения работ (обязателен, решение владельца 2026-10-06)

> Причина: расследования и ресёрчи (`.cluster/`, `DELIVERY/`, вложения чатов)
> оставались только в рабочей области агента — для канона «не существовали» и
> терялись. Владелец распорядился: **вся информация о работах LOVII сохраняется
> в каноне, особенно артефакты изысканий.**

## Куда складывать

Единственный дом канона LOVII: **`/Users/best/LOVII/lovii_docs`** (репо,
remote `hub` = `bestdeejay-design/lovii_docs`, ветка `main`).

1. **Ресёрчи и расследования** (диагностика, аудиты, ресёрч практик):
   `artifacts/RES-NNN-<slug>.md` (следующий номер — по REGISTRY) или пакет
   `artifacts/YYYY-MM-DD-<тема>/` (plan, субагенты, ревью, SQL, логи).
2. **Итоговые поставки** (сводные отчёты, HTML, скрин-пары, кадры до/после):
   `artifacts/YYYY-MM-DD-<ID>-deliverables/` с `README.md`-индексом.
3. **Каждый артефакт — строка в `artifacts/REGISTRY.md`**: файл · что это ·
   статус (актуален / на решении владельца / исторический). Нет строки в
   REGISTRY — артефакт для канона не существует.
4. **Задачи**: постановка — карточка `canon/TASKS/<ID>-<slug>.md` (формат —
   по образцу SZ-086/SZ-087/SZ-088), ссылка из `canon/BACKLOG.md` (только
   открытое; закрытое — в `BACKLOG_ARCHIVE.md`, §0.2). Никаких задач «только
   в чате».
5. **Ход работ** — `workspace/status.md` (блок сверху) и session-доки
   репозиториев (`<repo>/docs/sessions/NNN-<тема>.md`). Прогресс не писать
   в бэклог/карточку.

## Коммит и пуш

- После каждой поставки: `git add … && git commit` (conventional:
  `docs(artifacts): …` / `docs(canon): …`) и `git push hub main`.
- Пуш только в личный профиль `bestdeejay-design` (решение владельца
  06.10); зеркало `lovii-ru` синхронизируется отдельным шагом — не трогать.
- Секреты (ключи, токены, OTP) в git НЕ класть. Перед коммитом проверить
  diff: `.env`, токены, персональные данные владельца — маскировать/убирать.

## Правила существования артефакта

1. Файл вне `lovii_docs/artifacts` = файла нет. Переписка/чаты — не хранилище.
2. Временная рабочая зона (`.cluster/`, `tmp/`) — черновик; финал обязан быть
   скопирован в канон **до** завершения задачи.
3. Артефакт задачи ссылается на карточку задачи; карточка — на артефакт.
4. Если задача выполнялась по пункту бэклога (например O-2) — обновить
   пункт бэклога ссылкой на артефакт в том же коммите.

Агентские AGENTS-контракты ниже (AutoCoder Collaboration Contract и т.п.)
продолжают действовать; настоящий регламент **старше** них в части мест
хранения результатов LOVII.
