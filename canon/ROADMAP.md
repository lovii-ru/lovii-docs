# ROADMAP — Дорожная карта LOVII

<!-- fact-guard: allow — ROADMAP содержит метрики фаз (GMV, выручка, пороги); канон: PARAMS.md §7, FINANCIAL_MODEL.md -->

> **Назначение:** приоритизированный, привязанный к срокам план того, что и когда выходит, и что доказывает каждый этап. Майлстоуны упорядочены по **ценности для бизнеса** (а не по объёму работ), каждый содержит цель, ключевые фичи, доказательство (метрику) и целевую дату.
>
> **Связи:** видение продукта — `docs/VISION.md`, требования — `docs/PRD.md`. Статусы сверяются с `FEATURES.md` / `BACKLOG.md` (формируются параллельно).
>
> **Контекст модели:** LOVII масштабируется по городам через франчайзинговую модель **City Franchise**. Каждый город — отдельный white-label экземпляр экосистемы со своим каталогом, аудиторией и командой (гео-изоляция). Платформа — SaaS по лицензии (ООО «Аксиома»), работает по агентской схеме (глава 52 ГК РФ), все расчёты через банковского партнёра (Т-Банк, «Мультирасчёты») в рамках 161-ФЗ. Доход платформы — лицензионное вознаграждение, абонентская плата и роялти от франчайзи, а не маржа с товаров.

---

## Текущее состояние

Продукт находится на стадии **pre-MVP**. Сформирован пакет документации (BRD по реферальной системе, PRD демо, конкурентный анализ, параметры проекта, финмодель), зафиксирована агентская пилотная модель и тарифы Т-Банк (договор №МР-08.26/АКС_01). Пилот планируется на Василеостровском рынке (Санкт-Петербург). В работе — сборка MVP (PWA, 50 точек). Ближайший выкатываемый этап: живая пилотная экосистема в первом городе с легальным финансовым контуром.

## Майлстоуны (по ценности)

> Упорядочено по вкладу в ценность: сначала доказываем, что модель работает и приносит первую выручку (M1), затем включаем главный двигатель масштабирования — тиражируемый франчайзи-экземпляр города (M2), далее наращиваем удержание и LTV через лояльность (M3), дешевеющий рост через партнёрскую сеть (M4), новый поток дохода через рекламу (M5), зрелость платформы и экосистему (M6), выход на федеральную сеть и целевую оценку (M7).

### M1 — Живой пилот города №1 с легальным финансовым ядром · цель: Q4 2026

- **Цель:** клиент может заказать у местной точки, точка получает оплаченный заказ и легальный чек, платформа забирает комиссию и расщепляет её по агентской схеме. Доказывается, что юридическая и платёжная модель работает на реальных деньгах.
- **Фичи:** PWA-витрина (геофильтрация, поиск, 50 точек), оформление заказа (самовывоз/доставка), кабинет ТСП (каталог, приём заказов, финансы), курьер по приглашению, авторизация по SMS; агентская фискализация через облачную ККТ «Аксиомы» (54-ФЗ, признак агента + ИНН точки); мультисплит Т-Банк (карта 3,16% с НДС, СБП 0,7%, T-Pay 2,59% без НДС); вывод баллов через СБП. См. `docs/PRD.md` (MVP, домены 1–3, 9).
- **Доказательство:** ≥ 50 подключённых ТСП, ≥ 2 000 клиентов, ≥ 500 заказов/мес, NPS ≥ 40, 100% выплат точкам в срок, GMV пилота ≥ 7,2 млн ₽/мес (исходя из 50 точек × ~144 тыс. ₽/мес).
- **Статус:** 📋

### M2 — City Franchise: тиражируемый white-label экземпляр города · цель: Q1 2027

- **Цель:** запуск нового города превращается в повторяемую операцию. Каждый город — изолированный экземпляр (свой каталог, аудитория, команда франчайзи), управляемый из единой операторской консоли. Это главный двигатель масштабирования и источник роялти.
- **Фичи:** домен «Франчайзи» (управление точками, ПВЗ, рекламный доход локации), домен «Оператор» (тарифы, роялти, мониторинг, интеграции); шаблон white-label развертывания города с гео-изоляцией данных (кластер PostgreSQL на город, изоляция на уровне tenant); консоль оператора (АО «Точка») для мониторинга экосистем; пакет онбординга франчайзи (договор, брендинг, обучение).
- **Доказательство:** ≥ 1 подписанный франчайзи, время холодного запуска нового города ≤ 14 дней, к концу 2027 — 3–4 активных города (по прогнозу `PARAMS.md` §7.2), роялти 40% от пула LOVII (~5–8% от GMV) поступает в графике.
- **Статус:** 📋

### M3 — Программа лояльности и кросс-лояльность · цель: Q2 2027

- **Цель:** клиент возвращается ради баллов и единой карты лояльности на весь район. Растёт удержание и средний чек, формируется моат платформы.
- **Фичи:** конструктор лояльности для ТСП (кэшбэк в рублях, акции, условия), баллы 1:1 с гибридной оплатой (рубли + баллы), кросс-лояльность (конвертер баллов между точками, офлайн-оплата через QR), вывод баллов в рубли через СБП, чаевые. Комиссия платформы за кэшбэк 25% (распределение 40/40/20).
- **Доказательство:** 30-дневный retention > 40%, доля клиентов с активным кэшбэком ≥ 30%, объём выведенных через СБП баллов ≥ 1 млн ₽/мес на город №1 к концу квартала.
- **Статус:** 📋

### M4 — Партнёрская сеть и реферальная экономика · цель: Q3 2027

- **Цель:** рост числа точек идёт снизу вверх через сеть Амбассадоров и Представителей, снижая стоимость привлечения (CAC). Включается 2-уровневая модель дохода без каскада (не МЛМ).
- **Фичи:** промокоды (формат `PPXXXX`, префикс ветки Амбассадора), подписка Представителя (599 ₽/мес, по промокоду Амбассадора 199 ₽), лестница статусов Представитель → Мэр (≥30 точек) → Губернатор (3+ города × 30+ точек, выручка сети ≥ 15 млн ₽/мес), сплит пула 40/40/20 (Компания/Представитель/Амбассадор), UDID-счета и выплаты по `legal_status` (ИП/ООО push по графику, Самозанятый pull от 3 000 ₽; **вывод только с активной подпиской** — иначе баланс доступен только для оплаты товаров/тарифа), события (Школа, Каникулы).
- **Доказательство:** ≥ 40% новых ТСП подключаются по промокодам партнёрской сети, LTV/CAC > 3, в сети появляется ≥ 1 Мэр и ≥ 1 Губернатор.
- **Статус:** 📋

### M5 — Рекламная сеть и монетизация локации · цель: Q4 2027

- **Цель:** появляется второй поток дохода платформы — распределение рекламного дохода между участниками локации. Растёт ARPU без повышения комиссии с заказа.
- **Фичи:** домен «Реклама» (баннеры, таргетинг, распределение рекламного дохода между участниками), интеграция с рекламным агентом (ООО «Мобиап», 15–50% агентского вознаграждения), кабинет рекламодателя-ТСП (аналог RappiAds), промо-инструменты (купоны, Flash Deals).
- **Доказательство:** рекламный доход ≥ 5% от совокупной выручки платформы в активных городах, ≥ 20% ТСП запустили платную рекламную кампанию.
- **Статус:** 📋

### M6 — Зрелость платформы: API, white-label виджет, AI, HR · цель: Q1 2028

- **Цель:** LOVII становится платформой для экосистемы, а не только приложением. Открывается для сторонних сайтов и партнёров, появляются AI-рекомендации и HR-инструменты корпоративной мотивации.
- **Фичи:** домен «API» (REST/GraphQL, вебхуки, white-label виджет для сторонних сайтов), AI-рекомендации (умная лента, персонализация главного экрана по паттернам Яндекс Go / Glovo), домен «HR и обучение» (портал, рейтинги, корпоративная мотивация, интеграция с HR-партнёрами вроде Неолоджик), расширенная аналитика для оператора и франчайзи.
- **Доказательство:** ≥ 10 сторонних сайтов подключили white-label виджет, ≥ 30% заказов клиента инициируются из AI-ленты рекомендаций, NPS платформы ≥ 50.
- **Статус:** 📋

### M7 — Федеральная сеть (30–50 городов) · цель: Q2–Q4 2028

- **Цель:** выход на целевую оценку 3 млрд ₽ и подтверждение модели «экосистема, а не софт» на федеральном масштабе.
- **Фичи:** горизонтальное масштабирование франчайзи-экземпляров (гео-изоляция сохраняется), консолидированная аналитика всей сети, зрелый набор интеграций (DBS с федеральными ритейлерами, Чибис, локальная логистика), выделение агентских функций в отдельное юрлицо при появлении партнёра по масштабированию (см. `PARAMS.md` §8).
- **Доказательство:** 50+ городов, 7 000+ ТСП, 3 млн MAU, GMV ≥ 7 млрд ₽/мес, роялти «Точке» ≥ 260 млн ₽/год, EBITDA ≥ 250–300 млн ₽/год, целевая оценка 3 млрд ₽ (EBITDA × 10–12).
- **Статус:** 📋

- **Каденция:** ежемесячно.
- **Участники:** продукт, техлид, юр. служба (при необходимости).
- **Входы:** статус `FEATURES.md`, метрики дашбордов (GMV, retention, выплаты), `IMPROVEMENTS.md`, прогноз `PARAMS.md` §7.2.
