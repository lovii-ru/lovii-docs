## Назначение

Этот файл отвечает на один вопрос: **«какие неочевидные находки сделаны в коде и инфраструктуре платформы и каков их статус?»**

Находка — это:
- неочевидное поведение кода (ловушка, которую следующий агент обязательно наступит снова);
- расхождение документации с кодом;
- системный риск (одно место ломает много другого);
- осознанное отклонение от канона, ожидающее решения владельца.

Чем находка **не** является:
- сбой доко-пайплайна `lovii_docs` («я запустил X и сломалось») → `canon/TROUBLESHOOTING.md`;
- идея новой фичи или улучшения продукта → `canon/BACKLOG.md`;
- канонический факт платформы (числа, тарифы, правила) → свой файл-дом по карте `DOCS_GUIDELINES.md` §4.

## Правила ведения

1. **ID** — `F-NNN`, сквозной инкремент (следующий свободный номер из индекса). ID не переиспользуются.
2. **Практика фиксации** (дублируется в `<lovii-findings-practice>` в `CLAUDE.md` каждого репо):
   - комментарий в коде рядом с местом: `// FINDING(F-NNN): <суть>`;
   - запись в этот журнал: строка в индекс + карточка ниже.
3. **Статусы:** `Open` → `Fixed` / `Documented` / `Wontfix`. Закрытые записи не удаляются — помечаются со ссылкой на коммит/док.
4. **Значений канона здесь нет.** Ссылки вида «канон: `PARAMS.md` §N» — да; копии чисел — нет (устав §5).
5. **Одна находка — одна карточка.** Если находка перерастает в задачу — она уходит в `canon/BACKLOG.md`, карточка получает ссылку.

> **Гейт создания (DOCS_GUIDELINES §7):** файл создан 2026-09-06 **по решению владельца** (поручение в рабочем чате) без архивации существующего дока — осознанное исключение из правила «1 вход — 1 выход». Счётчик живых документов: 22 → 23 (отмечено в `canon/STATUS.md` и `DOCS_GUIDELINES.md` §7).

### F-003 · `lovii-app` · универсальное правило `* { color }` рвёт currentColor

- **Дата:** 2026-09-06 · **Статус:** Open (системный риск)
- **Суть:** `src/scss/normalize.scss` (родовой код продукта) содержит `* { color: var(--content-normal-primary) }`. Универсальный селектор красит **каждый** элемент напрямую — наследование обрывается на каждом узле, и `currentColor` внутри SVG всегда «чернильный», независимо от цвета родителя. Из-за этого иконка «Главная» в навигации не следовала цвету таба (канон демо нарушался); агент бился дважды, пока причина была найдена.
- **Локальный фикс (staging):** коммиты dc774a9 + 859dc7c — `color: inherit` на `.nav-ico`, `.nav-svg` и `&:deep(path)`; сердце иконки — литерал `#ffffff` (var() в presentation-атрибуте не гарантируется в FF/Safari).
- **Почему Open:** под риском **любая** будущая иконка на `currentColor`. Кандидат-решение: убрать `color` из `*`, перенести на `body` — но это глобальное изменение поведения, только по явному ок владельца.
- **См.:** `lovii-app` docs/sessions/006; комментарий в `NavBar.vue`.
