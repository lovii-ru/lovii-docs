# REFERENCE — карта документации LOVII

> **Назначение: КАРТА.** Постоянная карта документации LOVII: структура
> документов, ключевые факты, конвенции и связи. Агент сначала читает корневой
> `AGENTS.md` и `DOCS_GUIDELINES.md`, затем консультируется с карточкой этого
> файла — так контекст не смешивается и факты не разъезжаются.
>
> **Правило:** перед чтением/правкой документа найди его карточку в §3 и проверь
> файл-дом в `DOCS_GUIDELINES.md` §4. Перед созданием нового дока убедись, что
> вопрос не поглощается существующим; при изменении состава обнови эту карту и
> `REGISTRY.md`.
>
> **Публичные документы (важно):** четыре документа опубликованы на GitHub Pages
> (репозиторий `axiiom-ru/lovii`) и обновляются на месте без смены имени:
> 1. Публичная оферта — `public/Публичная_оферта.md`
> 2. Оферта присоединения — `public/Оферта_присоединения.md`
> 3. Схема движения средств LOVII — `public/money_flow_public.md`
> 4. Политика обработки персональных данных — `public/Политика_обработки_ПД.md`
> Публикация выполняется только через `scripts/sync-public.sh`; числовые факты
> сверяются с `PARAMS.md`, юридические формулировки — с внешним источником.
>
> **Кратко — необходимый набор:** §3.1 (канон: договор Т-Банк, PARAMS, BRD) +
> §3.2 (4 публичных дока) + §3.3 (ядро инженерных доков). Остальное — контекст
> или устаревшие дубли (§3.4, §3.7).

## 1. Карта репозитория

```
lovii_docs/
├── AGENTS.md / CLAUDE.md       # корневая точка входа и указатель
├── README.md / REGISTRY.md     # лендинг и ручная карта репозиториев
├── DOCS_GUIDELINES.md          # устав SSOT и гейты
├── canon/                      # канон + производные документы
│   ├── TASKS/                  # активные task-specs, рабочий класс W
│   └── ...
├── public/                     # четыре публикуемых документа класса C
├── archive/tasks/              # закрытые карточки с архивным баннером
├── archive/                    # версии, черновики и устаревшие дубли
├── contracts/openapi/          # машиночитаемый API-контракт
├── artifacts/ / marketing/    # рабочие и маркетинговые артефакты
├── scripts/                    # проверки и публикация
└── tbank/                      # справочная информация; договор — вне VCS
```

## 2. Иерархия истины (канон)

> При конфликте фактов выигрывает верхний. 🔻 ранг 1 = высшая власть.

1. **Договор Т-Банк** — локальный путь владельца
   `LOVII/lovii-docs/tbank/05_Мультирасчеты_без_акта_ООО_АКСИОМА.md`, вне GitHub/VCS
   и в свежем клоне отсутствует; единственный источник истины по комиссиям,
   НДС и юр. условиям приёма платежей (№ МР-08.26/АКС_01, Приложение №3).
2. **`PARAMS.md`** — консолидированный канон всех числовых параметров (ставки, пулы,
   сплиты). Если док показывает другое число — PARAMS побеждает.
3. **`BRD.md`** — продуктовый канон (согласованные решения, логика выплат самозанятым/ИП/ООО).
4. **Публичные документы (4)** — опубликованная истина для внешних сторон; обновляются на месте.
5. **Инженерные нарративные доки** (ARCHITECTURE, DATA_MODEL, API_SPEC, TEST_CASES, FINANCIAL_MODEL).
6. **Контекстные/исследовательские** (PROJECT_CONTEXT, START_VECTOR, FACT_MAP, COMPETITOR_ANALYSIS и др.) —
   низшая власть, могут расходиться.
7. **`archive/` и `versions/`** — исторические копии, НЕ авторитетны.
   `contracts/openapi/lovii.yaml` — наоборот, машиночитаемая истина API-домена.

> Любое расхождение (напр. оферта vs PARAMS) заносится в §4, а не правится молча.
