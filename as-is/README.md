## Формат каждого дока

1. «Что это» — модуль в двух словах.
2. «Путь покупателя» — что видит пользователь.
3. «Как работает» — API, данные, бизнес-правила (каждый факт с `file:line`).
4. «Чего нет / ограничения» — фактические заглушки.
5. «Кандидаты в „не хватает“» — открытые вопросы для фазы правок (решает владелец).
6. «Сверка владельцем» — вердикты и правки по факту ревью (дописывается по ходу).

## Правила работы

- Факт = `file:line`; базовый срез 2026-09-17, дельта-правки помечены датой
  (обновлено 19.09) — при изменении кода строка обновляется рядом с пометкой.
- «Как есть» ≠ «как надо»: предложения пишем только в раздел «Кандидаты»,
  а запуско-значимые пробелы — дублируем в [00](00-zapusk-chego-ne-hvataet.md).
- Числовые параметры (%, суммы, пороги) — ссылкой на канон, без копирования.
- Ритм: мерж/приёмка → обновить затронутые модули → сверить очередь в 00-доке.
