  b2b-юзер `osnovatel`, membership owner), счёта: partner/1 = 100 000₽ (`starter_opening`),
  platform_nominal/0 = 0, user/1 = 10 000₽ (кошелёк + `adjustment`-проводка с ledger-ногой).
- **Чего нет (намеренно):** мерчантов, точек, товаров, заявок, заказов, правил лояльности
  (кэшбэк по умолчанию 0 — решение владельца 28.09), канала Т-Банка в `payment_settings`
  (секреты заводятся в админке), прочих юзеров (тестовые 2–4 удалены 04.10).

  проде создан вручную при сиде; **с 04.10 есть и миграция** (core
  `2026_10_04_120000…`, conditional + `IF NOT EXISTS`, в staging batch 44) —
  новые контуры получают замок миграцией.
- Финансовые инварианты: «balance = Σ ledger» и «wallet = Σ tx» — 0 расхождений (аудит 04.10).

## Индексы поиска (аудит 04.10)

- `users.phone` — уникальный btree: вход/OTP/поиск по телефону — мгновенно.
- `cards.number` — уникальный btree: номера карт. PAY-карты = детерминированный хэш
  счёта, поиск не нужен (резолвинг вычислением + `accounts(owner_type,owner_id)` unique).
- Полнотекст (товары) — Meilisearch, не Postgres.
- Нет (и пока не нужно): индекс по `first_name/last_name` (LIKE-поиск админки —
  опция pg_trgm на больших объёмах), индекс `lovii_b2b.partner_users.phone`
  (вход b2b идёт через `core_user_id`, который проиндексирован).
