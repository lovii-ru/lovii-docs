## 0. БЛОКЕР — дефект стража дизайн-системы (правится первым)

Правила `font-size-literal` и `font-family-literal` в `src/__tests__/design-system.guard.test.ts`
записаны с **инвертированным** условием `keep`: нарушением считается **наличие токена**,
а «голые» пиксели пропускаются. Итог — страж наказывает корректный код и не видит некорректный.

Доказательства:

- `scss/variables.scss` целиком состоит из `calc(var(--font-scale, 1) * Npx)`, но в baseline
  висит как **24 нарушения**.
- Прямо сейчас `npx vitest run src/__tests__/design-system.guard.test.ts` падает:
  `ProfileTransfer.vue · font-size-literal: 15 (было 0)` — на **корректной** правке.

Правка (полярность):

```ts
// font-size-literal
keep: (value) => !(value.includes("var(--font-scale") || value.includes("var(--lv-")),
// font-family-literal
keep: (value) => !value.includes("var(--lv-font"),
```

Затем пересчитать baseline (правило меняет смысл метрики):

```bash
DS_GUARD_UPDATE=1 npx vitest run src/__tests__/design-system.guard.test.ts
```

Ожидаемый сдвиг baseline (замерено): font-size 71 → 295, font-family 12 → 1,
сумма 1579 → 1767 — всплывает реальный долг, который правило раньше не видело.

## 2. Постановка: экран «Промо» кабинета МСП — динамический выбор

Цель: на экране «Промо» дать связный выбор **МСП (юрлицо) → мерчант (бренд) → торговая точка**,
чтобы содержимое промо-раздела перестраивалось под выбранный уровень.

### 2.1. Выбор уровня

- Три связанных селектора в одном блоке: юрлицо → бренд → точка.
- Переиспользовать системный паттерн свитчера (`roles-module/components/PartnerSwitcher.vue`:
  чип в шапке + bottom-sheet) и/или системный select — **без локальных примитивов**.
- Значения каскадные: смена юрлица сбрасывает бренд/точку; смена бренда сбрасывает точку.

### 2.2. Динамика содержимого

- **Уровень точки** — правила точки (текущее поведение `MspLoyalty.vue`).
- **Уровень мерчанта** — агрегат по точкам бренда + возможность задать правило на бренд
  (наследование на все его точки).
- **Уровень МСП** — сводка по мерчантам.
- Под выбранный уровень пересчитываются: «Итог по точке», бюджет/метр, предпросмотр покупателя.

### 2.3. Пустые состояния и устойчивость

- Нет точек / нет брендов / нет правил — осмысленные пустые состояния (системный `role-empty`).
- Длинные названия юрлиц/брендов/точек **не вылезают** за края (перекос, line-clamp, ellipsis) —
  это уже начато, довести на всех уровнях.

### 2.4. ДС и проверки

- Только токены канона (`--lv-pad-x`, `--lv-block-gap`, `--lv-section-gap`, `--lv-r-*`,
  `calc(var(--font-scale,1)*Npx)`), без локальных `<style>`-примитивов.
- Гейт: `yarn test:unit && yarn type-check && yarn build-only` (read-only; полный `yarn test`
  переписывает дерево — только на чистом).
- Скриншоты: 390 и 1280, светлая/тёмная, для каждого уровня выбора.

### 2.5. Критерии приёмки

1. Каскад работает: смена юрлица/бренда/точки меняет данные промо без перезагрузки.
2. Для бренда видно наследование правил его точкам; для юрлица — сводка.
3. Тексты не обрезаются и не выходят за границы ни на одном уровне.
4. Нет новых нарушений стража (после фикса из §0).
5. Скриншоты обоих размеров и тем приложены к отчёту.

## 4. Главный дефект «Промо» — заголовок карточки прилипает к краю (исправлено)

Точная причина (замер 27.09): в системном слое приложения у заголовка карточки
`.role-section-head` (mix-in `src/modules/roles-module/styles/cabinet-ui.scss`) **потерян боковой инсет**,
который есть в дизайн-каноне (демо: `.role-section-head{ padding: 0 var(--lv-gutter) }`).
Карточка `.role-card` паддинга не имеет, тело карточки задаёт свои 16px — а заголовок шёл с нулём
и липнул к кромке.

Правка: в mix-in `role-section-head` добавлен `padding-inline: var(--lv-pad-x)`.
Проверено на экране «Промо»: заголовки «Кэшбэк по умолчанию», «Группы товаров», «Акции»,
«Итог по точке» теперь имеют отступ как у тела.

ЗАДАЧА zcode: правка системная — проверить остальные кабинеты на **двойной инсет**
(там, где заголовок уже лежал внутри падденной обёртки): `MspOverview`, `MspProducts`, `MspOrders`,
`MspBranchSettings`, `MspPayment`, `MspTeam`/team-*.vue. Где двойной — убрать обёртку или ноль на месте.
