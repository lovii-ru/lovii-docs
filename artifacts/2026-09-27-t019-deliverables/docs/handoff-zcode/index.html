2. Постановка: «Промо» МСП — динамический выбор

  • Выбор уровня: юрлицо → бренд → точка; каскад (смена родителя сбрасывает детей); системный свитчер/select, без локальных примитивов.
  • Динамика: точка → правила точки; бренд → агрегат по точкам + правило на бренд с наследованием; юрлицо → сводка по мерчантам. «Итог по точке», бюджет и предпросмотр покупателя пересчитываются под выбор.
  • Устойчивость: пустые состояния (нет точки/бренда/правил); длинные названия не вылезают (перекос, line-clamp, ellipsis).
  • ДС: только токены канона; гейт yarn test:unit && yarn type-check && yarn build-only; скриншоты 390/1280 × 2 темы для каждого уровня.

3. Критерии приёмки

  • Каскад меняет данные промо без перезагрузки.
  • Для бренда видно наследование правил точкам; для юрлица — сводка.
  • Тексты не обрезаются и не выходят за границы на всех уровнях.
  • Нет новых нарушений стража (после фикса §0).
  • Скриншоты обоих размеров и тем приложены.
