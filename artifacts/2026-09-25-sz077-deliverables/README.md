## Содержимое

- `sz077-report.html` — самодостаточный сводный отчёт (один файл, открывается двойным щелчком,
  кадры вшиты): итог, инвентаризация точек движения балансов, разбор узла и экрана, матрица гейтов,
  скрин-пара, решения и отклонения.
- `screens/` — исходные кадры скрин-пары `приложение ↔ витрина` на 390 и 1280:
  - `app-transfer-390.png`, `app-transfer-filled-390.png` — приложение, пустое и заполненное состояние;
  - `app-transfer-1280.png`, `app-transfer-filled-1280.png` — то же на широком экране;
  - `vitrine-transfer-390.png`, `vitrine-transfer-1280.png` — эталон `lovii-demo/#/transfer`.

## Как снято

Локально: витрина `lovii-demo` и реальная сборка приложения (`yarn build-only`) под Chrome через
Playwright, сервис-воркер заблокирован; у приложения API заглушен детерминированными фикстурами.
Это визуальное сравнение с эталоном, а не проверка на стенде — живую приёмку делает владелец.
