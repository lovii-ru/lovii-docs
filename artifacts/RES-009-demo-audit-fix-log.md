## 1. Баг «две стрелки выезжают на профиле с телефона» — найден, исправлен, задеплоен ✅

**Симптом (владелец, с телефона):** на странице профиля выезжают две иконки-стрелки, «как у документации».

**Диагноз:**
- Строки «Мои адреса» (`#/addresses`) и «История заказов» (`#/orders`) — единственные ряды `mNavRow`, идущие через голый `<a href>` с хвостом `icon('chev-right','icon')` → `<svg class="icon" viewBox="0 0 24 24">` **без width/height**.
- Класс `.icon` никогда не был определён в CSS (проверено `git log -S` по всей истории) — при том что хедер icons.js декларирует «размер — через CSS-класс».
- Chrome (десктоп/Android) схлопывает такой SVG в 0×0 — баг невидим на компе; Safari/iOS даёт размер по собственному алгоритму замещаемого элемента → стрелка раздувается и вылезает за карточку.

**Фикс:** `a8a86be` (2026-09-19) — базовое правило `.icon { width:16px; height:16px; flex-shrink:0 }` в css/lovii.css; бамп `lovii.css?v=52→53`, SW-кэш `lovii-v49→v50`, метка сборки 50. Точечные правила (.home-popular 32px, .ops-link 16px, .collapse__chev) специфичнее — не задеты. Верификация: playwright 390px — оба SVG 16×16 внутри строки; live-проверка curl — сборка 50 и правило `.icon` отдаются (2026-09-20).

**Осталось:** подтверждение владельца с телефона (после реактивации SW: закрыть/открыть PWA).

## 2. Navbar-токен — найдено, НЕ исправлено (ждёт команды) 🟧

`--lv-navbar-height` не определён в demo → `--lv-navbar-offset` считается от fallback 56px при фактическом таббаре 64px (подробности в RES-008 §5). Фикс подготовлен, код не пушим до чистой сессии.
