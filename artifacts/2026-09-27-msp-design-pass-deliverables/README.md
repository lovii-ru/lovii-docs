# 2026-09-27-msp-design-pass-deliverables — кабинет МСП: дизайн-проход по состояниям

Пакет по задаче [`T-026`](../../canon/TASKS/T-026-msp-cabinet-design-pass.md).
Сессия: продукт-дизайнер доводил экраны сценария подключения точки (МСП ↔ представитель),
собирал состояние отказа, форму заявки и канон уведомлений, а затем подготовил выпуск.

## Что в пакете

| Отчёт | О чём |
|---|---|
| `reports/lovii-msp-application-block/` | Блок заявки в кабинете МСП: карточка состояния отказа (одна карточка, причина строкой, действия), копирайт по строкам, типографика, обе темы |
| `reports/lovii-rep-approvals-audit/` | Дизайн-аудит экрана «Заявки» представителя: замеры (гуттер, отступы, кнопки, тап-таргеты), сжатие карточки очереди |
| `reports/lovii-rep-approvals-app/` | Экран апрува в приложении: мерчант/юрлицо, ИНН/ОГРН, причина отказа владельцу, сведения демо↔приложение |
| `reports/lovii-form-audit/` | Аудит формы заявки: рамки полей, крестик очистки 44px, шапка-заголовок, высота сабхедера |
| `reports/lovii-form-design/` | Форма заявки: верхний отступ по канону, подписи, кнопки |
| `reports/lovii-notifications-tones/` | Шпаргалка уведомлений: шесть тонов, семантика, рендер в двух темах |
| `reports/lovii-toasts-contrast/` | Тост при отмене: контраст тонов AA в двух темах и найденный дефект цвета текста |
| `reports/lovii-msp-run-status/` | Ход прогона сценария: лимит неподтверждённых юрлиц, привязка точек к промокоду |
| `reports/lovii-release-2026-09-27/` | Записка выпуска: состав, порядок выкладки, проверки, риски |

## Как снято

Локальный стенд приложения (`:5175`), демо-витрина (`:8090`), локальное ядро. Chrome/Playwright, 390px и 1280px,
обе темы. Замеры — через computed styles живого DOM; визуальная проверка — распознаванием изображений.

## Артефакты кода (для выкладки)

- приложение: ветка `t019-owner-design-pass` (lovii-app);
- ядро: патч `core-status-labels-and-resources.patch`;
- демо: патч `demo-copy-and-toasts.patch`.
