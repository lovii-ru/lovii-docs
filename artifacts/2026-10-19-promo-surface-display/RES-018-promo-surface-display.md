# RES-018 · Показ промо-механик на витрине: бейджи, штампы, тексты лент

Дата: 2026-10-19. Исполнитель: zcode. Статус: ресёрч проведён, ключевые рекомендации применены
(см. «Применено»), часть — на решении владельца.

## Тема 1. Бейджи на карточках товаров

- Лимит 1–2 бейджа на карточку; больше — badge blindness ([Baymard badge UI](https://baymard.com/blog/badge-ui), [Plumrocket](https://plumrocket.com/blog/ecommerce-product-badges), [NN/g banner blindness](https://www.nngroup.com/articles/banner-blindness-old-and-new-findings)).
- Иерархия: скидка −% → подарок/комбо → кэшбэк → штампы → информационные ([CROBOX](https://www.crobox.com/blog/ecommerce-product-badging)).
- Текст бейджа — только цифра и знак: «−10%», «−100 ₽»; слово «Скидка» в бейдже избыточно (оно для баннера/строки чекаута).
- Цвет = механика на всех поверхностях: скидка красный, бонусы зелёный, комбо/подарок — акцент бренда, часы — оранжевый.
- Если механика покрывает всю категорию — бейджи не дублируем, показываем плашку подборки.

## Тема 2. Прогресс штампов

- Канон формулировки: «Каждый 3-й — в подарок» (механика) + «у вас 2 из 3» (прогресс). Не «купи 2 получи 1».
- Гостю без истории — только механика, без «0 из 3».
- Счёт — по завершённым заказам; в корзине — прогноз ([LoopyLoyalty](https://blog.loopyloyalty.com/how-to-create-a-digital-punch-card-the-ultimate-guide-af53462353b5), [Wolt Storefront Loyalty](https://merchant.wolt.com/en/geo/storefront-loyalty-terms)).
- Поверхности: бейдж на товаре участнике; полный прогресс — страница точки/программы; прогноз — корзина; «штамп получен» — после заказа.

## Тема 3. Тексты лент

- Формула: заголовок = офферта с цифрой (≤40 знаков) → подзаголовок = условие/срок (≤60) → CTA ([Rocketium 3Cs](https://rocketium.com/academy/tips-to-create-an-ecommerce-banner), [AmandaCopy](https://www.amandacopy.com/business-tips/banner-ads-best-practices-conversions)).
- Срок конкретный («до 26 октября»), не «успей».
- Один словарь механик на всех поверхностях; расхождение бейджа ленты и итога корзины — причина брошенного чекаута (Baymard).
- Наблюдения по скринам Яндекс Еды/Самоката/Wolt — «референс рынка», не исследовательский факт.

## Рекомендации для канона Лови (на решение владельца)

1. Переименование «Кэшбэк» → «+N% бонусами» в UI — сквозное (кошелёк, леджер, лента), требует вердикта.
2. Цветовая карта механик в токенах lovii-design.
3. Полные условия акции — страницей «Правила акции» (сейчас нет поверхности).

## Применено 19.10

- Лимит 2 бейджа на карточку с иерархией; скидка на витрине «−N%».
- Штампы: бейдж «Каждый N-й — в подарок» на товарах-участниках группы (гостевая форма, без счётчика).
- Квитанция: прогресс штампов «…· у вас 2 из 3» вместо двоеточия.
