## Ключевые решения

1. Публичный репозиторий — только координационный слой. Код, секреты, PII и
   security-детали остаются в приватном контуре.
2. Одна задача = одна ветка = один PR. Арена не мержит.
3. SZ проверяет независимо; без evidence — `CHANGES REQUIRED`.
4. База — `staging`, не `master`. Промоушен — отдельное решение владельца.
