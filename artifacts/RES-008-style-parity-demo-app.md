## 3. Архитектура стилей — разная по замыслу

| | lovii-demo | lovii-app |
|---|---|---|
| Компонентный слой | глобальный `css/lovii.css` (3915 строк, 787 классов) | слоёный SCSS: normalize → палитра `tokens.scss` → канон `lovii-tokens.scss` → `mixins.scss` → типографика `variables.scss` (шкала канона docs/03, множитель `--font-scale`) → оверрайды `main.scss` + scoped-стили 146 Vue-компонентов + `cabinet-ui.scss` (1096 строк) |
| Токены | снапшот `assets/lovii-tokens.css` | тот же канон в `lovii-tokens.scss` |
| Тёмная тема | `data-theme="dark"` в токен-слое | тот же механизм — паритет |
| Типографика | h1 26px/800/1.22 — совпадает с миксинами app; **нет** `--font-scale` | `--font-scale` (настройка «Размер текста») + контрастные оверрайды светлой темы (Task 89: `--lv-dim` #6b6b6b вместо #888, ссылки pink-dark, статус-тиффани) |

## 5. Системное расхождение №1 — navbar-токен в demo 🟧

Demo рендерит таббар **64px** (`.app-nav-in { height: 64px }`), но токен `--lv-navbar-height` **не определён** → `--lv-navbar-offset` (css/lovii.css:1397) считается от fallback **56px**. Блоки с `calc(var(--lv-navbar-offset) + 8px)` встают вплотную к таббару на iPhone (safe-area). App считает от канонных 64px (SZ-013 — там же комментарий о жалобе владельца на перекрытие).

**Фикс (1 строка в demo, НЕ применён — ждёт команды):** определить `--lv-navbar-height: 64px;` рядом с `--lv-navbar-offset`.
