Выборы реализации

T-014 — clipboard

Отдельный helper src/package/global-helpers/clipboard.ts: Clipboard API → legacy textarea+execCommand, возвращает boolean, никогда не бросает. При неудаче — честный тост, ссылка/код остаются читаемым выделяемым текстом. referral.ts не тронут: его «тихие return» — корректная семантика чистых функций, уже выведенная в UI.

T-015 — тестовая OTP-маска

Вариант (б): резолвер OtpDeliveryTargetResolver вызывается в SendOtpAction до гейтов каналов и доставки (единой общей точки у транспортов нет — MAX/TG/VK паркуют сессию раньше). Сессия, cooldown, профиль и dev-стор — по маске; в проверки привязки и в send() идёт эффективный телефон. Маска — одна константа /^\+7000\d{7}$/. Флаг OTP_TEST_REDIRECT_ENABLED (default false), получатель OTP_TEST_REDIRECT_TO; в production маска запрещена (otp_test_phone_forbidden); каждый редирект пишется логом.

T-016 — сброс подписки

Статус — только машиной состояний: Active → Cancelled (reason admin_action); из GracePeriod/Suspended — легальным двухшаговым путём через Active; Cancelled — идемпотентный no-op. forceFill служебных полей — в одной внешней транзакции со всем сбросом. Перевыпуск промокода — RepresentativePromoService::issue() с фолбэком на ветку Основателя AA. Прод-гейт через app()->environment('production').
