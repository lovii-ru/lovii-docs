## Как снято

- Playwright (chrome, viewport 390×844 @2x, fullPage), вход по OTP через
  `dev/otp/last-code` (локальный стенд). Скрипты: `~/.cluster/t034-state-shots/capture.mjs`
  (не канонизированы — одноразовый прогон; для повторов лучше перенести в capture-toolkit).
- Тестовый заказ №463 создан через API (guest session → cart/items → orders/checkout,
  самовывоз, точка 1024) — ради кнопок статусов и confirm-отмены в кабинете МСП.
- Формы только открывались и закрывались: **ничего не опубликовано и не сохранено**
  (визард закрыт «К списку» до публикации, формы товара/категории/приглашения — без сабмита).
