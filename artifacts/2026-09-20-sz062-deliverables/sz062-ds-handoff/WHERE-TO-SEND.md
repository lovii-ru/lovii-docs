# Куда отправить бриф (большая модель)

Загрузите эти 4 файла (или вставьте их текстом) и промпт:

- `BRIEF.md` — контекст и задача
- `lovii.css` — продуктовый CSS (главный объект аудита)
- `lovii-tokens.css` — токены
- `lovii-design-components.css` — компонентный слой канона
- `PROMPT.txt` — готовый промпт (скопировать первым сообщением)

## Куда (модели с длинным контекстом; ~250 КБ текста — нормально):

1. **Claude** — https://claude.ai (загрузить файлы через скрепку). Хорош по архитектуре CSS/ДС.
2. **ChatGPT** — https://chatgpt.com (загрузить файлы). 
3. **Gemini** — https://gemini.google.com (длинный контекст, загрузка файлов).
4. **DeepSeek** — https://chat.deepseek.com.

Порядок: сначала сформулировать задачу промптом, затем приложить файлы. Если контекст ограничен — можно отдать только `lovii.css` + `lovii-tokens.css`.

> Важно: это ваш проектный код/токены. Если что-то не должно уходить во внешний сервис — отдайте только токены и структуру, без данных.
