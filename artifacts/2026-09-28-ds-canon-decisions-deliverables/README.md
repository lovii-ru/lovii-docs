## Как снято

Стенд :5175 (lovii-app, ветка `t020-wallet-contour-sz081`), Chrome/Playwright, замеры
computed styles на живом DOM; контрасты — расчётом по WCAG 2.1; ширины текстов —
canvas-замером в Inter 14px. Макеты вариантов — на реальных токенах приложения.

## Ключевые факты (для карточек)

- Кнопка: белый текст 14/700 на светлом краю градиента `#f64a8a` = **3.35** (норма 4.5);
  кандидаты: светлый край `#d6336f` → 4.60; сплошной `#c92a6a` → 5.22.
- Пилюля адреса: доступно **109.3 px** при логотипе **152.7 px** → «Невский про…»;
  в пустом состоянии — «Выбрат…». Варианты: лого по демо (118/92) → улица целиком
  при 92; + тема в настройки на телефонах → длинные улицы.
- Чип «ожидание» (светлая): `#8a6a25` на soft-gold = 4.25–4.48; кандидаты `#856621` (4.52–4.77),
  `#80611e` (4.86–5.13). Тёмная тема не меняется (6.26).
- Поле размера m: **42 px** (норма 44) — правка +2 px по всей системе.
- Кнопка «назад» субхедера: **40×40** — варианты: зона 44 невидимым слоем / видимая 44.
