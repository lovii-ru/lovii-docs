# 2026-09-28-sz080-auth-otp-design — вход и OTP: канонический макет

Дизайн-пакет к задаче SZ-080 (`archive/tasks/SZ-080-otp-screen-applock-pattern-logo-cells.md`):
канонический экран входа и кода (OTP). До кода — на приёмку владельца.
Запрос владельца 28.09: «начинаем с экрана авторизации и OTP — думаю, ты сразу его сделаешь каноничным».

Связано: `SZ-025` (AppLock — источник паттерна), `SZ-012 §2.5` (длина кода 4), `T-021` (auth-гард
не задеть), `T-019` (только токены).

| `assets/` | Кадры «до» со стенда :5175 (light/dark), логотипы (light/dark), шрифт Inter |

## Решения макета

- **Логотип 30px** по центру — паттерн пинкод-экрана (AppLock) и зеркало авторизации
  в демо-каноне (`.auth-logo img{height:30px}`, тема — свой вариант).
- **Заголовок 22/800** (`-0.01em`), **по центру** (правка владельца 28.09) — как заголовки шагов авторизации в демо (`.auth-step h3`).
- **4 ячейки 64×72** (зазор 12, радиус `--lv-r-md`, фон `--lv-surface`, бордер `--lv-line-strong`;
  активная — `--lv-pink` + кольцо; ошибка — `--feedback-negative-solid`) вместо узкого
  подчёркивания 148px.
- **Одна строка статуса** (aria-live, min-height 20px): таймер → повтор → «Проверяем код…» →
  ошибка. Лечит жалобу «тексты наезжают, экран прыгает».
- Логика не меняется: таймер 60с, честный повтор, `EXPECTED_LENGTH = 4`, авто-подстановка
  (`autocomplete="one-time-code"` + маска `####`); тест-иды `auth-confirming`, `auth-resend-code`,
  `auth-resend-error` сохранить.
