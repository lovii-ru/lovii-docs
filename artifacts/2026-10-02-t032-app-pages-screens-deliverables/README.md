  OTP-логин через дев-эндпоинт). Спеки: `pages-map-shots.spec.ts` (7 секций) + `pages-map-fixups.spec.ts`
  (точечные пересъёмки). Копии: `capture-toolkit/`.
- **Профиль:** тест-профиль владельца `+79119287478` (user 51) — роли `representative`, `ambassador`,
  `msp`, `founder` — все ролевые кабинеты доступны на стенде.
- **Формат кадров:** viewport 390×844 @2x, полная высота страницы, светлая тема, реальные данные стенда.
- **Файлы по секциям съёмки (63):** гость 10 · покупатель 22 · представитель 6 · платформа 7 ·
  амбассадор 5 · МСП 9 · команда 4 — карточки 006–008 сняты в двух видах. Плюс 3 новых файла
  точечной пересъёмки — итого **66 PNG** (60 карточек канона).

## Как перезапустить

```bash
cd lovii-app

# 1) (опционально) обновить токен профиля — OTP через дев-эндпоинт стенда
node ../.cluster/app-pages-shots/tools/login-check.mjs

# 2) основная съёмка (7 секций)
E2E_TARGET=staging E2E_CHANNEL=chrome PAGES_SHOTS=1 \
PAGES_SHOTS_OUT=/Users/best/LOVII/.cluster/app-pages-shots/raw \
PAGES_SHOTS_STATE=/Users/best/LOVII/.cluster/app-pages-shots/state \
npx playwright test --config=e2e/playwright.config.ts e2e/tests/pages-map-shots.spec.ts

# 3) пересъёмка особых экранов (адрес-форма кликом; mock-банк; «История» заказов)
E2E_TARGET=staging E2E_CHANNEL=chrome PAGES_SHOTS_FIXUPS=1 \
PAGES_SHOTS_OUT=/Users/best/LOVII/.cluster/app-pages-shots/raw \
PAGES_SHOTS_STATE=/Users/best/LOVII/.cluster/app-pages-shots/state \
npx playwright test --config=e2e/playwright.config.ts e2e/tests/pages-map-fixups.spec.ts

# 4) сборка: manifest + превью + покрытие, галерея, проверка галереи
node ../.cluster/app-pages-shots/tools/merge-and-thumbs.mjs
node ../.cluster/app-pages-shots/tools/build-gallery.mjs
node ../.cluster/app-pages-shots/tools/gallery-check.mjs
```

`PAGES_SHOTS_RESUME=1` — не переснимать уже существующие кадры; `-g 'съёмка: МСП'` — только одна секция.
Скрипты `tools/*.mjs` — cwd-независимые (пути резолвятся от расположения скрипта; запускать можно из любой директории);
команды Playwright (шаги 2–3) выполняются из `lovii-app`.
Спеки — временные файлы в `lovii-app/e2e/tests/` (в репозиторий не коммитились); их копии — в `capture-toolkit/`.

## Ограничения и риски

- Данные — состояние staging на дату съёмки; после изменения данных стенда кадры можно переснять (см. выше).
- Снят дефолтный (светлый) вариант темы; тёмная тема и edge-состояния (ошибки сети, скелетоны) в комплект не входят.
- Full-page артефакт: фиксированный нижний таб-бар на длинных экранах отображается один раз в середине кадра — поведение Playwright fullPage, не дефект приложения.
- Токен профиля хранится локально (`state/token.json`) и в git не публикуется; кадры содержат реальные данные тест-профиля стенда.
- Спеки в `lovii-app/e2e/tests/` — временные (untracked); при желании закоммитить их в репо — обсудить с командой.
