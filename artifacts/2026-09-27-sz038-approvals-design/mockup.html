Сейчас как есть

Карточка показывает только название точки для каталога (application.name — «Продукты у дома») и город/адрес. Наименования юрлица нет вообще.

Причина: в ответе API (ресурс очереди апрува) просто нет поля с юрлицом — фронт физически нечего показать.

Предлагаем макет

  • Шапка карточки: название мерчанта (бренда) крупно, под ним — юрлицо. Так сразу видно, что за бренд подключаем.
  • Реквизиты: ИНН и ОГРН — отдельными строками, проверяемость (КПП не показываем).
  • Что подключаем: адрес точки, контакт, промокод (кто привёл), дата подачи.
  • Действия: один главный акцент — «Подтвердить», рядом вторичное «Отклонить».

Порядок очереди — по дате подачи; карточки одного типа, уровни иерархии не смешиваются.

Что нужно от API в работу

  • добавить в ресурс очереди апрува поля юрлица: наименование, ogrn (КПП не показываем; источник — снимок DaData в заявке, уже сохраняется);
  • название бренда/мерчанта по заявке;
  • если реквизитов нет (ИП без КПП / внешний источник недоступен) — показывать «—», а не пустоту.
