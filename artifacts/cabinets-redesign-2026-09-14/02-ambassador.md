## 2. Целевая IA (5 вкладок — состав сохранён)

`Обзор · Представители · Доход · Обучение · Чаты`

### Обзор

1. **KPI 2×2:** Доход · месяц (accent pink — честный ноль до финконтура с пояснением); Представители N (tap → Представители); Точки в структуре (gold); GMV структуры · месяц (pink + delta).
2. **Next-step card (gold):** контекстное одно действие — «Проведи созвон с N представителями, им нужна помощь» → Обучение; или «План недели: разбор цифр → созвон → лиды».
3. **Моя структура — дерево:** «Ты · амбассадор» → представители (имя, город, точки, доход/мес, delta) → их точки (имя, категория, chevron → карточка точки на витрине). Дерево — главный экран смысла роли: «за кем я закреплён и чем владею».
4. Топ представителей (hbars) + Рост структуры (area 6 мес).
5. Quick actions: Представители · Обучение · Доход · Чаты.

### Представители

- Канон-список: имя + delta роста, «город · N точек · названия», справа доход/мес. Тап → **bottom-sheet с деталями представителя** (точки списком, GMV, рост) + кнопка чата.
- **Read-only закрепление — вместо кода:** заметка «Ветку назначает платформа. Новые представители попадают в структуру через промокоды своих представителей». Код-карточка «AMB-Город-777» выведена — противоречит канону (ввода кода амбассадора не существует, BRD §2.4).
- Дерево структуры под списком.

### Доход

- KPI: Доход амбассадора · месяц (accent); Доход LOVII сети (gold); Средний доход/представителя (tiffany); GMV структуры (pink).
- Модель-ноут: «Доля амбассадора — 20% пула branch-wide со всей ветки, за обучение и мотивацию представителей. Пул платформы — 10% чека минус эквайринг».
- Чарты: 6 мес (area gold), по представителям (hbars), история выплат («кураторская выплата»).
- До финконтура — честный ноль с пояснением.

### Обучение

- Mentor-card (ink-gradient) + прогресс-кольцо («Пройдено N из M уроков, X% обученности»).
- Уроки с мини-прогрессом и статусами (Пройдено / В процессе / Начать), время.
- Инструменты: скрипт продаж, шаблоны документов, калькулятор дохода.
- План недели (timeline): Пн разбор цифр · Ср созвон · Пт лиды.

### Чаты

Групповой «Все представители» + личные; в app — отложено (см. README, вопрос №3).

## 3. Данные (roles-api)

`ambassadorDashboard()`: prefix, reps_count, points_count (+ сервер отдаёт поля, которые UI сейчас игнорирует). Для нового UI добавить: список представителей с точками и GMV, план недели/уроки (уже есть в core config), прогресс обучения.
