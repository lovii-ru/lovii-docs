# screens-library — единая библиотека экранов LOVII

**Открывать:** `library.html` (локально двойным кликом, публично —
https://lovii-ru.github.io/lovii-docs/screens-library/library.html после пуша в хаб).

## Что это

Один корпус вместо разрозненных пакетов: **все экраны + все их развёртки
(кадры состояний) + все версии каждого кадра** в одном манифесте и на одной
странице. Актуальные скрины — по умолчанию; история версий — переключателем
«история (N)» на карточке или галочкой «показывать все версии».

Состав (на момент сборки): 60 страниц APP-P · 9 модалок APP-M · 86 версий · 126 кадров.

## Адресация (главное)

Каждый кадр имеет полный код вида:

```
APP-P-049 · v2-2026-10-03 · step2-combo-FIXED
```

- `APP-P-049` — страница (канон `canon/APP_PAGES/APP-P-049-msp-loyalty.md`);
- `v2-2026-10-03` — версия съёмки (папка в `screens/`);
- `step2-combo-FIXED` — развёртка (имя PNG внутри версии; `default` — основной кадр).

Код копируется кнопкой ⧉ прямо с кадра в библиотеке. В ревью/задачах/тестах
достаточно указать этот код — маршрут и способ попадания на экран ищутся в
карточке канона, ссылка на неё есть в шапке каждой карточки библиотеки.

## Как пополняется

1. Снять новые кадры (стенд/локально) → сложить в `screens/<slug>/<vN-YYYY-MM-DD>/`
   через `node screens/_tools/screens-publish.mjs --from <каталог съёмки> …`
   (см. `screens/README.md`). Никогда не перезаписывать существующие версии —
   только новые `vN`.
2. Если у кадра есть логика-код (визард, ветвление) — дополнить/переиспользовать
   `screens-gallery/states.json` (коды подтянутся в библиотеку автоматически).
3. Пересобрать: `node screens-library/_tools/build-library.mjs`
   (переписывает `manifest.json` и `library.html` целиком — оба только генерируются).
4. Ревью — в `REVIEW.md` (append-only, сквозные R-номера, формат внутри файла).

## Файлы

| Файл | Что | Кто пишет |
|---|---|---|
| `manifest.json` | единый манифест (генерируется) | только build-library.mjs |
| `library.html` | страница библиотеки (манифест зашит внутрь, офлайн) | только build-library.mjs |
| `REVIEW.md` | живой журнал ревью, R-001… | человек/агент, append-only |
| `_tools/build-library.mjs` | генератор | правка по мере надобности |
| `_tools/library.template.html` | шаблон страницы | правка по мере надобности |

Источники: `screens/` (истина), `screens-gallery/manifest.json` (заголовки/группы),
`screens-gallery/states.json` (коды логики кадров), `canon/APP_PAGES/` (карточки).
