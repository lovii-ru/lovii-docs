# Решения владельца C4–C6 + C1 attestation (2026-10-06)

Ответы владельца на открытые пункты аудита. Фиксируются как канонические
решения; в CLOSEOUT-3/вердикт арены включаются дословно.

## C4 — Production approval

**Решение: риск принят владельцем.** Прод-деплой запускается только
вручную владельцем (`gh workflow run ci.yml --ref master` под его
аккаунтом). Required reviewers технически недоступны: GitHub API
возвращает HTTP 422 «billing plan does not support the required
reviewers protection rule» — подтверждено дважды (05.10 и 06.10) на
плане Team. Пустой environment `ci-selfhosted` удалён.

**Оговорка:** план владельца — Team (платный). Если GitHub включит
required reviewers для Team-плана environments — вопрос о C4 переоткрыть.

## C6 — «CI вне прод-хоста»

**Решение: цель принята, но не сразу — как фича через пару месяцев.**
До переезда действуют компенсирующие меры (уже внедрены): контейнерные
раннеры без host docker.sock, изолированные сети пар, resource limits
dind, forced-command деплой. Residual risks (privileged dind, TLS off
внутри пары, mutable tags) — приняты до переезда.

## C1 — Off-site (закрыт 05.10, подтверждение)

Off-site работает: Яндекс.Диск, ночной дамп, retention 14, restore-тест
пройден (sha256 совпадает, pg_restore --list 113 TABLE DATA).
Аттестация исполнителя; аккаунт Яндекс подтверждён владельцем
(«ты яндекс уже настраивал, там есть ключ и облако»).
