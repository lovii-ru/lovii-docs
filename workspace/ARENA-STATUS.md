## Порядок работы с ареной (устоявшийся регламент)

1. **Снапшот.** Арена ходит ровно в ОДИН репо: `rucorp/lovii-audit-snapshot`
   (внутри все lovii-* на пин-срезах + AUDIT-BRIEF.md). Перед каждым её
   запуском снапшот пересобирает zcode-агент (git archive origin/staging
   каждого репо → README-пины → push; ~5 мин). Старые срезы арены живут
   ветками `arena/<hash>-…` и мержатся в main после приёмки.
2. **Задача** = issue в снапшот-репо (или в репо проекта, если скоуп один).
   В issue: скоуп, стоп-лист «не переоткрывать», формат отчётов, ограничения
   (деньги — только чтение; код не менять).
3. **Сдача** = запушенная ветка на GitHub + ссылка в ответе. Локальный
   коммит = не результат. Неясности — вопрос в issue ДО старта.
4. **Приёмка** = zcode-агент: fetch → чтение отчётов → проверка ключевых
   находок по живому коду → мерж ветки в main → сводка владельцу
   (таблица: конфирмед/не подтверждено/решение владельца).
5. **Фиксы** = отдельные ветки в lovii-* с тестами, полный гейт (core/b2b —
   chuwi-core-tests.sh / b2b-tests.sh, app — test:unit+type-check+build),
   session-дока, пуш в staging, CI, приёмка владельцем. Денежная зона —
   дифф показывается владельцу до staging.
