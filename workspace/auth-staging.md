# Авторизация и регистрация на staging

## Покупатель (app-staging.lovii.ru)

Вход и регистрация — одно и то же: телефон → канал → код. Пользователь создаётся
в core автоматически (`SendOtpAction → User::firstOrCreate`).

Тест-профиль владельца: +79119287478 (зарегистрирован, «Сергей BEST»).

Код на staging — три способа:
1. **Универсальный `1234`** — работает; после ввода 4 цифр появляется кнопка
   «Подтвердить» → нажать. (Фикс задеплоен 09-06, коммит b357c13.)
2. **Настоящий код** из dev-эндпоинта:
   `https://api-staging.lovii.ru/api/v1/dev/otp/last-code?phone=+7XXXXXXXXXX`
   → JSON `{"phone":..., "code":...}`.
3. Реальная SMS — только если канал настроен на реального провайдера; на staging
   транспорты по умолчанию `log` (код уходит в лог сервера, не в телефон).

Тест-профиль владельца: +79119287478 (зарегистрирован, «Сергей BEST»).

## Локальная сборка (локальный стенд core + app dev)

Тот же бипас: `OTP_DEV_BYPASS=true` в локальном `.env` core → **код `1234`
принимается для любого номера**, канал доставки логовый, реальная SMS не
уходит. Ключи MAX/TG/VK перенесены с сервера в локальный `.env` (2026-09-14),
так что экран выбора каналов показывает те же три (MAX · Telegram · ВКонтакте)
с тем же состоянием, что на staging (`GET /auth/request-code` отвечает
`coming_soon: false` для всех трёх).

## Кабинет партнёра (b2b-staging.lovii.ru)

1. Открыть https://b2b-staging.lovii.ru/panel → вход по телефону → код (те же 1234
   или из эндпоинта — b2b подтверждает код через Core API).
2. Если партнёра ещё нет — автоматом на /panel/register: многошаговая регистрация
   (данные компании/точки) → создаётся Partner + PartnerUser (владелец, unverified)
   + membership.
3. Ограничение: не более 5 неподтверждённых партнёрств на пользователя
   (`MAX_UNVERIFIED_OWNED_PARTNERS = 5`).
4. Партнёр после регистрации unverified — верификация (инвойс) пока заглушка
   (invoice.pdf 404 намеренно), полный цикл верификации — следующий этап.

## Супер-админка (admin-staging.lovii.ru/admin)

Регистрации нет — только назначенные через Shield RBAC пользователи.
Чтобы получить доступ, нужно назначить роль существующему core-пользователю
(команда/сид в lovii-admin — по запросу).

## Боты Telegram / MAX

Для staging не нужны: каналы работают через log-транспорты, код всегда доступен
через 1234 или dev-эндпоинт. Реальные боты/провайдеры понадобятся только перед
продом (отдельная задача).
