# Цикл МСП: витрина → товары → заказы (инструкция, v0.1)

> **Для кого:** владелец (первое прохождение на своих компаниях), дальше —
> цепочка «владелец → амбассадор → представитель → торговая точка».
> **Стенд:** b2b-staging.lovii.ru + app-staging.lovii.ru
> **Составлено из кода lovii-b2b / lovii-core** (не по памяти): ресурсы,
> поля и статусы — фактические, на 2026-09-09.

## Шаг 0. Вход

1. Открой `https://b2b-staging.lovii.ru`.
2. Вход по телефону (+OTP; на staging код придёт в Telegram/MAX или бипас `1234`).
3. Кабинет показывает данные твоего партнёра (ООО «АТМОСФЕРА» / ООО «АКСИОМА» —
   обе верифицированы 2026-09-09).

## Шаг 1. Мерчант (витрина компании)

Меню **«Мерчанты»** (группа «Мерчанты») → **Создать**.

Поля: `name` (название витрины), `slug` (адрес), `merchant_type`, `description`,
`phone`, `support_phone`, логотип (`logo_url`, квадрат), `mini_logo_url`,
`logo_background_color`.

- У АТМОСФЕРЫ мерчант уже есть: **Pizza Napoli** (id 280).
- Для АКСИОМЫ создай новый (это и есть тренировка).

## Шаг 2. Филиал / торговая точка

Меню **«Филиалы»** (Branch) → **Создать**. Филиал = точка, куда придёт заказ.

Ключевые поля: `name`, `status`, **`pickup_available`** (самовывоз) и
**`delivery_available`** (доставка), `min/max_delivery_minutes`,
`min_order_amount` (минимальная сумма заказа), адрес (пикер с подсказками:
`address_line` + координаты + `city_id` + `timezone`, есть ручной ввод),
`working_hours`. К филиалу (Relation manager) — **зоны доставки** (DeliveryZones).

Без активного филиала заказ оформить нельзя — покупателю нужно куда-то ехать/доставлять.

## Шаг 3. Категории каталога

Меню **«Категории»** → Создать: `parent_id` (вложенность), `name`, `is_active`,
`image_url`. Категории — дерево внутри мерчанта.

## Шаг 4. Позиции (товары)

Меню **«Позиции»** (Position = витринный товар, таблица `merchant_offers`).

Поля: `category_id` (дерево категорий), `title`, `description`,
`price_rubles`, `old_price_rubles` (зачёркнутая цена), **`is_available`**
(в продаже / скрыт), фото (`media`), **`all_branches`** или конкретный
`branch_id`, `offer_type`, `sku`, `barcode`, `stock_qty` (остаток).

Массовые действия в списке: **клонировать**, «включить продажу»,
«выключить продажу».

После сохранения позиция попадает в поиск витрины автоматически (Scout →
Meilisearch через очередь Horizon; полная пересборка — командой
`sync:search-index`). Если не появился — проверь `is_available`, `status`
мерчанта=Active и филиал активен.

## Шаг 5. Проверка витрины (глазами покупателя)

1. `https://app-staging.lovii.ru` (лучше инкогнито — сбросить PWA-кэш).
2. Поиск по названию мерчанта → карточка витрины → категории → товар.
3. Добавь в корзину, выбери филиал (самовывоз/доставка), оформи заказ.

⚠️ В поиске много Kuper-витрины (импорт прошлых времён) — ищи свой мерчант
по точному названию.

## Шаг 6. Приём заказа

1. **b2b → «Заказы»** (группа «Заказы»): список с блоками «Заказы сегодня /
   Активные / Завершённые». Открыть заказ → просмотр.
2. Смена статуса — кнопка **«Сменить статус»** (transition) или **«Отменить»**.
   Лестница статусов (машина состояний):
   `created → submitted → accepted → preparing → ready → handed_to_delivery
   → on_the_way → completed`; внеочередные: `cancelled`, `failed`.
   Переходы валидируются — «перепрыгнуть» нельзя.
3. **Telegram**: на сервере живёт orders-поллер — заказы приходят ботом
   в привязанный чат (привязка бота к мерчанту/точке делается командой
   /start в боте заказов; см. Telegram-контур).

## Шаг 7. Что в этом цикле НЕ работает (так и задумано)

| Механизм | Статус |
|:---|:---|
| Оплата заказа покупателем | Нет (нет эквайринга в заказе; заказ заканчивается статусом) |
| Выплаты партнёру | Нет (Трек I, финансовый контур) |
| Гейт витрины по `verified_at` | В коде нет; спека — BACKLOG **I-5** (партнёры пока видны независимо от верификации) |
| Фискальный чек | Нет (Трек I-1) |

## Грабли

- Kuper-мерчанты в поиске — не пугайся, ищи по своему названию.
- Изменил логотип/название мерчанта — витрина обновится после переиндексации,
  не мгновенно.
- Заказ не приходит в Telegram — проверь, что бот заказов привязан
  (поллер на сервере crash-ует без токена в .env — это серверная часть).
- PWA-кэш app: если витрина «старая» — инкогнито или сброс кэша.
