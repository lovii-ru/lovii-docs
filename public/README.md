# LOVII — цифровая платформа локальной экономики

**LOVII** — SaaS-платформа для микро-, малого и среднего предпринимательства (МСП): объединяет локальный бизнес — пекарни, кофейни, магазины, химчистки, салоны, рынки и службы доставки — в единой цифровой инфраструктуре с общей программой лояльности.

> **Простыми словами:** «Лови» — приложение, где собраны все местные кафе, пекарни, магазины и сервисы твоего района. Это единая карта лояльности на весь район: баллы, кэшбэк и витрина локального бизнеса в одном месте.

---

## Основная цель

Построить **комплексную информационную платформу локальной экономики (КИП)** — цифровую витрину и экосистему лояльности, которая:

- даёт **микробизнесу** готовую цифровую инфраструктуру и короткий путь к собственному клиенту;
- даёт **клиентам** единую программу лояльности на все местные точки района (баллы, кэшбэк, кросс-обмен);
- **агрегирует локальные сервисы** вместо конкуренции с федеральными агрегаторами (Яндекс, Ozon);
- масштабируется по городам через **франчайзинговую модель** (City Franchise): каждый город — отдельный экземпляр экосистемы со своим каталогом, аудиторией и командой (white-label, гео-изоляция).

## Суть модели

- **Лицензионная модель:** платформа — ПО по лицензии (SaaS), не владеет товарами, не перепродаёт и не хранит деньги клиентов.
- **Все расчёты проходят через банковского партнёра** (Т-Банк, Мультирасчёты) в рамках 161-ФЗ — автоматическое распределение платежей между участниками.
- **Доход платформы** — лицензионное вознаграждение и абонентская плата, а не маржа с товаров.

## Юридическая модель: агентская схема

Платформа LOVII (ООО «Аксиома») работает с торговыми точками по **агентской схеме** (глава 52 ГК РФ): «Аксиома» — **торговый агент (поверенный)** Принципала (торговой точки), действует от своего имени, но за счёт Принципала, обеспечивая приём заказов, приём платежей и фискализацию.

- **Приём платежей** — на **номинальный счёт** «Аксиомы» (ст. 860.1 ГК РФ, 161-ФЗ) с автоматическим расщеплением (сплитованием) выручки и комиссии банком-партнёром (Т-Банк, продукт «Мультирасчёты»).

> **Примечание:** Режим работы с номинальным счётом и продуктом «Мультирасчёты» АО «Т-Банк» требует подтверждения банков по письменному договору. До момента получения такого подтверждения расчёты осуществляются в порядке, согласованном сторонами отдельно.
- **Фискализация** — **силами Агента** через собственную облачную ККТ «Аксиомы» (54-ФЗ); в чеке указываются признак агента и ИНН торговой точки как Поставщика.
- Правоотношения регулируются нормами агентирования, что **исключает квалификацию деятельности «Аксиомы» как платёжного агента** по смыслу 103-ФЗ.

### Роли сторон в правоотношениях

| Сторона | Роль | Зачем |
|:---|:---|:---|
| **ООО «Аксиома» (Платформа)** | **АГЕНТ** — коммерческий посредник и ИТ-инфраструктура | Выводит компанию из-под 103-ФЗ; налог — только с агентского вознаграждения (комиссии) |
| **Торговая точка (МСП)** | **ПРИНЦИПАЛ** — владелец товара и главный Продавец | Вся ответственность за товар/услугу и налоги с продаж (по чекам с её ИНН); не нужно настраивать свой интернет-эквайринг и ККТ |
| **Покупатель** | **ПОТРЕБИТЕЛЬ** | Получает мгновенный легальный электронный чек (Агент + ИНН точки-поставщика) |
| **Банк (Т-Банк, «Мультирасчёты»)** | **ТЕХНИЧЕСКИЙ ИСПОЛНИТЕЛЬ** (номинальный счёт) | Расщепляет входящий платёж: 90% — точке, комиссия — Агенту |

### Порядок подключения контрагентов (Принципалов)

1. **Регистрация и акцепт оферты** — МСП регистрирует кабинет, вносит реквизиты (ИНН, ОГРН, счёт) и принимает Оферту присоединения. С этого момента заключён смешанный лицензионно-агентский договор.
2. **Авто-открытие субсчёта в Т-Банке** — платформа через API передаёт ИНН/реквизиты в «Мультирасчёты»; банк привязывает счёт точки к номинальному счёту «Аксиомы» и ежедневно переводит чистую выручку (90%).
3. **Наполнение витрины и запуск** — МСП загружает меню/каталог, проходит модерацию, статус «Активна».

### Цикл одного заказа

- Покупатель оплачивает заказ; деньги поступают на номинальный счёт, Т-Банк мгновенно расщепляет: 90% — точке, комиссия — «Аксиоме».
- Сервер LOVII шлёт сигнал в облачную кассу «Аксиомы», прикрепляя ИНН торговой точки.
- Облачная касса формирует электронный чек (признак агента + ИНН точки как Поставщика) и отправляет Покупателю.
- Торговая точка видит уведомление о 100% оплате и готовит заказ.

### Подготовка «Аксиомы» к работе по схеме

- **Юридическая:** обновление текстов оферт (агентская схема + фискализация силами Агента); проверка ОКВЭД в ЕГРЮЛ (основной 47.91, вспомогательный 62.01); согласование с Т-Банком работы «Мультирасчётов» с агентской моделью и номинальным счётом.
- **Техническая (ККТ и ОФД):** договор с провайдером облачных касс (Атол Онлайн / Бизнес.Ру / CloudKassir); аренда облачной ККТ и ФН (рекомендуется ФН на 36 мес.); регистрация кассы в ФНС с обязательной галочкой «ККТ используется при осуществлении деятельности платёжного агента / поверенного / агента»; договор с ОФД.

## Что включает платформа

**ПО для МСП** объединяет 12 функциональных доменов:

| № | Домен | Что входит |
|:--|:--|:--|
| 1 | **Общая архитектура** | Ролевая модель (клиент / торговая точка / курьер / представитель / амбасадор), безопасность, темизация |
| 2 | **Клиентская часть** | Витрина, каталог, заказ, программа лояльности, баллы, вывод через СБП, чаевые |
| 3 | **Бизнес-часть / ТСП** | Каталог товаров, приём и обработка заказов, касса, персонал, доставка |
| 4 | **Франчайзи** | Управление точками, пункты выдачи (ПВЗ), рекламный доход локации |
| 5 | **Оператор** | Тарифы, роялти, мониторинг, интеграции, управление экосистемой |
| 6 | **Логистика** | Доставка (Igoods, Яндекс.Go, Чибис), курьерские заказы, статусы |
| 7 | **Реклама** | Баннеры, таргетинг, распределение рекламного дохода между участниками |
| 8 | **Кросс-лояльность** | Конвертер баллов между точками, обмен баллов, офлайн-оплата через QR |
| 9 | **Финансы и юр. инфраструктура** | Консолидатор платежей, самозанятые (НПД), банковский партнёр (БПА / Мультирасчёты) |
| 10 | **HR и обучение** | Портал, обучение, бонусы, рейтинги, корпоративная мотивация |
| 11 | **API** | REST / GraphQL, вебхуки, white-label виджет для сторонних сайтов |
| 12 | **Дополнительно** | Локализация, поддержка, модерация, AI-рекомендации |

### Роли в экосистеме

- **Клиент** — покупает в маркетплейсе, получает баллы лояльности
- **Торговая точка (Лицензиат)** — бизнес на платформе, работает с заказами
- **Курьер** — доставка по приглашению оператора
- **Цифровой представитель / Мэр / Губернатор** — партнёрская сеть развития городов
- **Амбасадор** — обучение и мотивация партнёрской сети

### Тарифы для торговых точек

| Тариф | Абонплата | Комиссия с заказа |
|:--|:--|:--|
| **Лови Старт** | 0 ₽/мес (до 30 000 ₽ выручки) | 0% |
| **Лови Базовый** | 0 ₽/мес | 10% |
| **Лови Про** | 2 990 ₽/мес | 4–7% + абонплата |

### Технологический стек

- **Frontend:** Vue 3 + Vite + Tailwind CSS (PWA — прогрессивное веб-приложение)
- **Backend:** микросервисы + event-driven, Node.js / Go
- **Данные:** PostgreSQL, Redis
- **MVP:** PWA (прогрессивное веб-приложение)

### Соответствие требованиям

152-ФЗ (персональные данные), 161-ФЗ (платёжные системы), 54-ФЗ (кассы), 115-ФЗ (антиотмывочный), PCI DSS, KYC/AML — хранение данных в РФ.
